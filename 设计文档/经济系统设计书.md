# 经济系统设计书

## 1 概述

### 1.1 设计目标

本文档定义织女-7先遣星球上的经济系统，涵盖信用点体系、开发树、供销机制、制造系统、物流系统、配额制与本地市场。经济系统是连接 [物品设计书](file:///workspace/设计文档/物品设计书.md)、[装备系统设计书](file:///workspace/设计文档/装备系统设计书.md)、[世界场景设计书](file:///workspace/设计文档/世界场景设计书.md) 的核心枢纽，驱动资源生产、物资流转与装备供应的完整循环。

经济系统设计遵循以下原则：

- **组织性优先**：玩家天然处于先遣基地组织之中，经济活动服务于星球开发的整体规划，而非个人投机。
- **计划性表达**：通过开发树（树状科技树）体现有规划、有依赖的系统性发展，而非自由市场的无序生长。
- **隐蔽的意识形态**：采用通用货币体系降低理解门槛，通过"跟着基地计划走收益最稳定"的体验，自然传递组织性与计划性的价值。
- **三层解锁逻辑**：原材料（产地+物流）→ 工业品（生产线）→ 装备成品（关键事件），每一层的解锁逻辑不同，体现不同生产环节的特点。
- **自动化生产**：生产线建成后持续自动产出，玩家精力放在"建什么、建在哪、多大"的决策上，避免枯燥的重复操作。

### 1.2 社会主义意识形态的表达

本经济系统在设计上融入社会主义意识形态的核心要素，但以游戏机制的方式自然呈现，避免生硬说教：

| 要素 | 游戏机制体现 | 体验表达 |
|------|--------------|----------|
| 计划与组织 | 开发树（有规划的发展路径）、供需清单（基地发布需求） | 玩家感受到"为整体目标而生产"，而非漫无目的 |
| 集体利益 | 开发进度为暗线（所有玩家贡献累积推进基地发展） | 玩家的生产活动直接推动基地升级，产生集体荣誉感 |
| 按需分配 | 配额制（基础保障+高级按需领取） | 体现"各取所需"的分配原则，高级配额按需解锁 |
| 劳动价值 | 积分来自交付物资（劳动产出），而非投机倒把 | 玩家通过生产劳动获得回报，而非资本积累 |
| 互助协作 | 物流线维护、供应链补全 | 玩家的生产活动互相支撑，体现共同体精神 |

### 1.3 核心框架

经济系统由以下核心机制构成：

```
┌─────────────────────────────────────────────────────────────┐
│                        经济系统核心循环                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  生产活动 → 交付物资 → 推进开发树 + 获得信用点               │
│     ↑                                              ↓         │
│  建造/探索 ← 解锁新设施/新产地 ← 开发树节点解锁              │
│     ↑                                              ↓         │
│  物流维护 ← 物流线事件 ← 开发树解锁物流线路                  │
│                                                             │
│  信用点 → 交易终端（合规物资）/ NPC小贩（自由交易）           │
│  配额制 → 基础保障（免费补给）/ 高级奖励（按需领取）          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2 核心概念

### 2.1 信用点（CR）

信用点是织女-7先遣星球的通用货币，用于所有经济活动的计价与交易。

| 属性 | 说明 |
|------|------|
| 获取方式 | 向基地供需清单交付物资、完成任务奖励、NPC小贩交易 |
| 使用场景 | 交易终端采购、配额商店购买、NPC小贩交易 |
| 流通范围 | 基地内所有交易终端、NPC小贩、玩家间（未来联机） |
| 价值锚定 | 与基地供需清单的收购价挂钩，避免恶性通胀 |

**信用点获取示例**：

| 物资 | 交付数量 | 获得信用点 |
|------|----------|-----------|
| 铁矿石（MIN001） | 100单位 | 500 CR |
| 钢锭（REF002） | 50单位 | 2000 CR |
| 75mm炮弹（AMM001） | 10单位 | 500 CR |

### 2.2 开发树

开发树是一个树状结构的科技发展图，体现先遣基地的有规划、有依赖的系统性发展。

#### 2.2.1 开发树结构

开发树采用三层结构，对应从原材料到装备成品的完整生产链：

```
┌─────────────────────────────────────────────────────────────────┐
│                        先遣基地开发树                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第一层：原材料供应（产地+物流）                                  │
│  ├── 铁矿脉群 → 物流线①                                        │
│  ├── 铜矿脉群 → 物流线②                                        │
│  ├── 钛矿脉群 → 物流线③                                        │
│  ├── 辉锗矿脉 → 物流线④                                        │
│  ├── 稀土矿脉 → 物流线⑤                                        │
│  └── ...                                                       │
│           ↓                                                     │
│  第二层：工业品加工（生产线）                                    │
│  ├── 钢铁加工线（依赖：铁矿脉群 + 物流线①）                     │
│  ├── 铜铝加工线（依赖：铜矿脉群 + 物流线②）                     │
│  ├── 钛合金加工线（依赖：钛矿脉群 + 物流线③）                   │
│  ├── 电子工业线（依赖：钢铁线 + 铜铝线 + 辉锗矿）               │
│  ├── 稀土加工线（依赖：稀土矿脉 + 物流线⑤）                     │
│  └── ...                                                       │
│           ↓                                                     │
│  第三层：装备成品（关键事件触发）                                │
│  ├── 基础载具供应（依赖：钢铁线 + 铜铝线）                      │
│  ├── 高级载具供应（依赖：钛合金线 + 电子工业线）                │
│  ├── 传奇载具供应（依赖：超导晶格 + 稀土加工线）                │
│  └── ...                                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 2.2.2 三层解锁逻辑

每层的解锁逻辑不同，体现不同生产环节的特点：

| 层级 | 解锁条件 | 玩家参与方式 | NPC并行行为 |
|------|----------|--------------|-------------|
| **原材料供应** | 探索/占领地图产地 + 解锁物流线 | 探索地图、占领矿脉据点、完成物流清障任务 | 其他先遣队员随时间自动解锁部分产地 |
| **工业品加工** | 前置原材料层已解锁 + 玩家建造生产设施 | 在据点建造冶炼炉、化工厂、制造工厂等 | NPC逐步建设基础生产线（钢铁、铜铝） |
| **装备成品** | 前置加工层已解锁 + 关键事件触发 | 完成遭遇战、特定任务或主动申请 | NPC在玩家触发事件后解锁供应 |

#### 2.2.3 开发进度与解锁

开发进度采用**暗线指标**机制：

- **进度累积**：玩家向供需清单交付物资时，自动累积对应开发节点的进度
- **进度显示**：玩家可通过专门的"开发进度面板"查看各节点进度与前置条件
- **解锁触发**：进度满或关键事件触发后，节点解锁，基地日志/新闻通知
- **解锁效果**：解锁下游节点的前置条件、新增交易终端物资、解锁配额

## 3 供销机制

### 3.1 供需清单

供需清单是基地常驻的物资收购与销售清单，是经济循环的核心接口。

#### 3.1.1 需求清单（收购）

基地发布的物资收购清单，玩家可随时交付物资换取信用点并推进开发进度。

**需求清单位置**：基地交易终端的"供销窗口"

**需求清单格式**：

| 物资类别 | 物资名称 | 收购价（CR/单位） | 开发进度推进 | 备注 |
|----------|----------|-------------------|-------------|------|
| 矿产 | 铁矿石（MIN001） | 5 | 推进铁矿脉群 | 基础原料，不限量 |
| 矿产 | 铁氧体（MIN002） | 8 | 推进铁矿脉群 | 高阶原料，不限量 |
| 矿产 | 铜矿石（MIN003） | 6 | 推进铜矿脉群 | 基础原料，不限量 |
| ... | ... | ... | ... | ... |
| 提炼产物 | 钢锭（REF002） | 40 | 推进钢铁加工线 | 工业品，不限量 |
| 弹药 | 75mm炮弹（AMM001） | 50 | 推进基础载具供应 | 弹药，不限量 |

#### 3.1.2 销售清单（采购）

基地配额商店与交易终端的物资销售清单，物资随开发树进度解锁。

**配额商店**：仅解锁配额的物资可领取，按需领取，价格远低于市场。

**交易终端**：所有已解锁的物资均可购买，价格接近收购价的2-3倍。

**销售清单格式**：

| 物资名称 | 配额商店价（CR） | 交易终端价（CR） | 解锁条件 |
|----------|------------------|------------------|----------|
| 75mm炮弹（AMM001） | 30 | 80 | 钢铁加工线解锁 |
| 5mm激光沉积结构修复剂（POT001） | 50 | 120 | 基础配额 |
| 25mm激光沉积结构修复剂（POT002） | 100 | 250 | 基础配额 |
| 基础载具组件 | 按需领取 | 20000 | 基础载具供应解锁 |
| 高级载具组件 | 按需领取 | 80000 | 高级载具供应解锁 |

### 3.2 交付机制

玩家向供需清单交付物资的流程：

```
1. 玩家选择交付物资
   ↓
2. 系统检查物资是否在需求清单中
   ├── 是 → 显示收购价与可推进的开发节点
   └── 否 → 提示"该物资暂不在收购清单中，可前往NPC小贩尝试出售"
   ↓
3. 玩家确认交付数量
   ↓
4. 系统执行交付
   ├── 扣除玩家物资
   ├── 增加玩家信用点
   ├── 推进对应开发节点进度
   └── 如进度满，触发解锁事件
   ↓
5. 显示交付结果（获得信用点 + 推进进度）
```

### 3.3 信用点计算

交付物资获得的信用点按以下公式计算：

```
获得信用点 = 物资数量 × 收购价
```

**示例**：
- 交付100单位铁矿石：100 × 5 = 500 CR
- 交付50单位钢锭：50 × 40 = 2000 CR

### 3.4 开发进度推进

交付物资对开发进度的推进按以下规则：

| 规则 | 说明 |
|------|------|
| 单位推进值 | 每单位物资推进对应开发节点1点进度 |
| 节点总量 | 每个开发节点需要的进度总量在面板上显示（如铁矿脉群需1000点） |
| 批量推进 | 批量交付按数量线性推进 |
| 阶段加成 | 开发进度达50%后，NPC并行贡献开始加速进度 |

## 4 制造系统

### 4.1 制造系统定位

制造系统是经济系统的核心产出环节，玩家通过建造生产设施，将原材料加工为工业品，供应基地或自用。

**制造系统特点**：
- **自动化生产**：设施建成后持续自动产出，玩家无需反复操作
- **规模弹性**：玩家可根据需求选择小规模（自用）或大规模（补足供应链）
- **战略决策**：玩家精力放在"建什么、建在哪、多大"的决策上
- **与开发树联动**：生产线的解锁依赖开发树前置节点

### 4.2 生产设施类型

#### 4.2.1 冶炼炉（金属冶炼）

| 设施名称 | 产出物资 | 依赖原材料 | 前置开发节点 |
|----------|----------|------------|-------------|
| 小型铁矿炉 | 铁锭（REF001） | 铁矿石 | 铁矿脉群解锁 |
| 中型钢铁炉 | 钢锭（REF002）、高强钢锭（REF003） | 铁矿石、铁氧体 | 铁矿脉群解锁 |
| 大型铜铝炉 | 铜锭（REF004）、铝锭（REF006） | 铜矿石、铝土矿 | 铜矿脉群解锁 |
| 钛合金炉 | 钛锭（REF008）、钛合金锭（REF009） | 钛矿 | 钛矿脉群解锁 |
| 钨钢炉 | 钨钢（REF021） | 钨矿石、钢锭 | 钨矿石解锁 |

| 设施名称 | 产出物资 | 依赖原材料 | 前置开发节点 |
|----------|----------|------------|-------------|
| 基础化工厂 | 硫酸（REF016）、盐酸（REF024） | 硫磺、盐矿 | 硫磺矿解锁 |

| 制药厂 | 生物酶解修复剂（POT010）、抗生素 | 生物材料、农产品 | 生物材料供应解锁 |

#### 4.2.3 制造工厂（工业品）

| 设施名称 | 产出物资 | 依赖原材料 | 前置开发节点 |
|----------|----------|------------|-------------|

| 电子工厂 | 电路板、芯片（IND007-008） | 硅晶、铜锭、稀土 | 电子工业线解锁 |

| 装甲工厂 | 装甲板毛坯（IND016） | 钢锭、钛锭 | 钢铁加工线解锁 |

### 4.3 建造与运行

#### 4.3.1 建造流程

```
1. 玩家选择建造地点（需在已解锁的据点/基地内）
   ↓
2. 选择建造的设施类型
   ↓
3. 系统检查前置条件
   ├── 开发树节点是否解锁
   ├── 建造所需物资是否充足
   └── 建造地点是否有足够空间
   ↓
4. 消耗物资，触发建造
   ├── 小型设施：即时完成
   ├── 中型设施：1-2游戏小时
   └── 大型设施：4-8游戏小时
   ↓
5. 建造完成，设施开始运行
```

#### 4.3.2 建造所需物资

| 设施类型 | 建造物资 |
|----------|----------|
| 小型铁矿炉 | 钢锭×50、混凝土块×20 |
| 中型钢铁炉 | 钢锭×200、混凝土块×80、螺栓×100 |
| 大型铜铝炉 | 钢锭×300、铜锭×100、混凝土块×100 |
| 钛合金炉 | 钢锭×400、钛锭×50、混凝土块×150 |
| 弹药工厂 | 钢锭×500、铜锭×200、螺栓×200、混凝土块×200 |

#### 4.3.3 运行机制

**持续产出**：设施建成后自动持续产出，无需玩家操作。

**产出速率**：

| 设施规模 | 单小时产出 | 说明 |
|----------|-----------|------|
| 小型 | 1-5单位 | 仅供自用 |
| 中型 | 10-50单位 | 可供应基地 |
| 大型 | 50-200单位 | 补足供应链 |

**产出存储**：产出物资存入基地仓库，玩家可随时领取或直接交付。

**中断条件**：
- 原材料不足：设施暂停产出，待原材料补充后恢复
- 物流线中断：相关原材料供应受阻，设施产出下降50%
- 设施损坏：战斗中设施可能受损，需维修后恢复

### 4.4 规模弹性

玩家可根据需求调整生产规模：

| 需求场景 | 建造策略 | 投入产出比 |
|----------|----------|-----------|
| 自用需求 | 建造1-2座小型设施 | 低投入，自给自足 |
| 基地供销 | 建造3-5座中型设施 | 中投入，稳定收益 |
| 供应链补全 | 建造大型设施集群 | 高投入，解锁装备供应 |

**示例**：
- 玩家仅需75mm炮弹自用：建造1座小型弹药工厂，每小时产出5发
- 玩家想供应基地钢铁：建造3座中型钢铁炉，每小时产出30钢锭
- 玩家想解锁高级载具：建造大型钛合金炉+电子工厂集群，补足供应链缺口

## 5 物流系统

### 5.1 物流系统定位

物流系统连接原材料产地与加工设施，是开发树第一层（原材料供应）与第二层（工业品加工）之间的纽带。

**物流系统特点**：
- **半显性**：物流线需要解锁，解锁后自动连接，但容量有限
- **风险存在**：物流线运行中可能触发减益事件，需玩家维护
- **可扩展性**：当前为被动减益模式，未来可扩展为任务响应模式

### 5.2 物流线解锁

#### 5.2.1 解锁条件

物流线的解锁需要同时满足：

1. 原材料产地已解锁（通过探索/占领）
2. 完成物流清障任务（首次解锁）

#### 5.2.2 物流清障任务

物流清障任务是一次性任务，解锁物流线后不再需要重复完成。

**任务示例**：

| 任务名称 | 任务目标 | 任务奖励 |
|----------|----------|----------|
| 1号物流线清障 | 前往铁矿脉群附近的物流节点，清除残留叛军 | 解锁铁矿→基地的物流线①，信用点×500 |
| 2号物流线清障 | 前往铜矿脉群附近的物流节点，击退小规模虫群 | 解锁铜矿→基地的物流线②，信用点×800 |

**任务流程**：
```
1. 基地发布清障任务
   ↓
2. 玩家接取任务
   ↓
3. 玩家前往任务地点（已解锁的地图位置）
   ↓
4. 触发战斗/事件
   ├── 清除叛军/虫群 → 任务完成 → 物流线解锁
   └── 战斗失败 → 任务失败，可重试
```

### 5.3 物流线运行

#### 5.3.1 运行状态

物流线解锁后自动运行，将原材料从产地运输至基地仓库。

**运行参数**：

| 参数 | 说明 |
|------|------|
| 运输速率 | 每小时运输100-500单位原材料 |
| 运输容量 | 单条物流线最大同时运输1000单位 |
| 连接范围 | 物流线仅连接对应产地与基地 |

#### 5.3.2 物流线管理

**物流线升级**：玩家可投入物资升级物流线，提升运输速率与容量。

| 升级等级 | 运输速率 | 运输容量 | 升级费用 |
|----------|----------|----------|----------|
| Lv1（初始） | 100单位/小时 | 1000单位 | 解锁时免费 |
| Lv2 | 200单位/小时 | 2000单位 | 钢锭×100、螺栓×200 |
| Lv3 | 300单位/小时 | 3000单位 | 钢锭×200、铜线×100、螺栓×400 |

**物流线面板**：

```
┌─────────────────────────────────────────────────┐
│              物流线管理                           │
├─────────────────────────────────────────────────┤
│                                                 │
│  ① 铁矿→基地                                    │
│  状态：✅ 运行中                                  │
│  运输速率：200单位/小时                           │
│  当前容量：1500/2000单位                          │
│  物流线等级：Lv2                                 │
│  [升级至Lv3]                                    │
│                                                 │
│  ② 铜矿→基地                                    │
│  状态：⚠️ 运输受阻（铁矿石供应-50%）              │
│  运输速率：100单位/小时                           │
│  当前容量：500/1000单位                           │
│  物流线等级：Lv1                                 │
│  [前往处理]（到达后触发清障任务）                 │
│                                                 │
│  ③ 钛矿→基地                                    │
│  状态：🔒 未解锁                                 │
│  解锁条件：钛矿脉群已解锁 + 完成清障任务         │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 5.4 物流线风险事件

#### 5.4.1 事件类型

物流线运行中可能触发以下减益事件：

| 事件类型 | 触发概率 | 减益效果 | 处理方式 |
|----------|----------|----------|----------|
| 数字叛军袭击 | 低 | 对应原材料供应-50%，持续3游戏天 | 被动减益，可前往触发点处理 |
| 虫群阻断 | 中 | 对应原材料供应-30%，持续2游戏天 | 被动减益，可前往触发点处理 |
| 设备故障 | 低 | 运输速率-30%，持续1游戏天 | 被动减益，自动恢复 |
| 气候异常 | 极低 | 物流线暂停，持续半天 | 被动减益，自动恢复 |

#### 5.4.2 事件处理

**被动减益模式**（当前实现）：
- 事件触发后，物流线自动施加减益
- 减益信息显示在物流线面板与基地日志
- 减益会在一段时间后自动恢复
- 玩家可选择前往事件地点处理，到达后自动触发清障任务，解决后立即取消减益

**未来扩展（任务响应模式）**：
- 事件触发后，生成可接取的清障任务
- 玩家必须完成任务才能取消减益
- 减益期间物资供应暂停，迫使玩家响应

#### 5.4.3 事件通知

事件触发时通过以下方式通知玩家：

1. **基地日志**：⚠️ "2号物流线遭虫群阻断，铜矿石供应下降30%"
2. **物流线面板**：显示减益状态与"前往处理"按钮
3. **地图标记**：触发事件的物流节点显示红色标记

## 6 配额制

### 6.1 配额制定位

配额制是经济系统的保障与激励机制，体现"按需分配"原则。

**配额制特点**：
- **基础配额**：保障日常战斗消耗，免费供应
- **高级配额**：成就驱动，按需领取，体现"各取所需"

### 6.2 基础配额

#### 6.2.1 配额内容

基础配额包括日常战斗所需的弹药与修复剂，在机库维修站可免费补给。

| 配额物资 | 每日配额 | 获取方式 |
|----------|----------|----------|
| 75mm炮弹（AMM001） | 30发 | 机库维修站免费补给 |
| 105mm炮弹（AMM002） | 20发 | 机库维修站免费补给 |
| 5mm激光沉积结构修复剂（POT001） | 5个 | 机库维修站免费补给 |
| 25mm激光沉积结构修复剂（POT002） | 3个 | 机库维修站免费补给 |
| 8μm等离子喷涂装甲修复剂（POT004） | 3个 | 机库维修站免费补给 |

#### 6.2.2 配额使用

**补给流程**：
```
1. 玩家进入机库维修站
   ↓
2. 点击"补充补给"
   ↓
3. 系统检查当日剩余配额
   ├── 配额充足 → 免费补给对应物资
   ├── 配额不足 → 提示"今日配额已用完，超出部分需消耗信用点购买"
   │   └── 玩家确认 → 按交易终端价购买
   └── 已超出 → 直接按交易终端价购买
   ↓
4. 显示补给结果（免费部分 + 付费部分）
```

**配额重置**：
- 每日零点（游戏内时间）重置基础配额
- 未使用的配额不累积至次日

### 6.3 高级配额

#### 6.3.1 配额内容

高级配额为载具与稀有装备，按需领取，需通过成就/事件解锁。

**可解锁配额（示例）**：

| 配额类别 | 具体物资 | 解锁条件 | 领取方式 |
|----------|----------|----------|----------|
| 基础载具 | 轻型侦察车 | 解锁"基础载具供应"节点 | 载具损毁后按需领取 |
| 基础载具 | 中型运输车 | 解锁"基础载具供应"节点 | 载具损毁后按需领取 |
| 高级载具 | 重型战斗车 | 解锁"高级载具供应"节点 | 载具损毁后按需领取 |
| 高级载具 | 离子炮载具 | 解锁"高级载具供应"节点 | 载具损毁后按需领取 |
| 传奇载具 | 反物质发生器 | 解锁"传奇载具供应"节点 | 载具损毁后按需领取 |
| 稀有材料 | 辉锗晶体 | 完成"辉锗矿脉占领"成就 | 按需领取 |

#### 6.3.2 配额解锁方式

高级配额通过以下方式解锁：

| 解锁方式 | 示例 |
|----------|------|
| 开发树节点解锁 | 解锁"基础载具供应"节点 → 基础载具配额解锁 |
| 关键事件触发 | 遭遇巨型守卫虫，基地解锁重型战斗车供应 |
| 任务完成 | 完成"辉锗矿脉清剿"任务 → 辉锗晶体配额解锁 |
| 成就达成 | 累计交付1000单位钛锭 → 钛合金载具配额解锁 |

#### 6.3.3 配额领取

**按需领取机制**：
- 载具配额：当前无该类型载具（已损毁或未持有）时可领取
- 材料配额：随时可领取，但领取后从配额中扣除

**领取流程**：
```
1. 玩家打开"配额商店"
   ↓
2. 查看已解锁的高级配额
   ↓
3. 选择要领取的配额物资
   ↓
4. 系统检查领取条件
   ├── 载具：当前是否持有该类型载具
   ├── 材料：当前配额是否充足
   └── 基地供应：对应供应链是否正常运行
   ↓
5. 条件满足 → 免费领取
   条件不满足 → 提示原因（如"请先放弃当前载具"）
```

#### 6.3.4 配额奖励选择

部分高级配额解锁时，玩家可在多个选项中选择一项解锁：

**示例**：
> 恭喜！你已解锁"高级载具供应"节点。请选择一项解锁：
> - A. 重型战斗车配额
> - B. 离子炮载具配额
> - C. 反物质发生器配额（需额外完成"反物质前体交付"成就）

## 7 本地市场

### 7.1 本地市场定位

本地市场是基地供销体系的补充，提供计划外的物资调剂渠道。

**本地市场特点**：
- **交易终端**：机构化大宗贸易，合规物资，供需定价
- **NPC小贩**：个体小批量交易，价格波动，未来扩展

### 7.2 交易终端

#### 7.2.1 终端定位

交易终端代表基地监管下的合规大宗贸易，是本地市场的主要交易场所。

**交易终端位置**：基地中央交易大厅

**交易终端功能**：
- 出售已解锁的合规物资（价格为收购价的2-3倍）
- 收购玩家的多余物资（价格略低于供需清单收购价）

#### 7.2.2 终端物资清单

交易终端的物资清单随开发树进度解锁：

| 物资类别 | 可交易物资 | 解锁条件 | 终端售价（CR） | 终端收购价（CR） |
|----------|-----------|----------|---------------|-----------------|
| 弹药 | 75mm炮弹 | 钢铁加工线解锁 | 80 | 30 |
| 弹药 | 105mm炮弹 | 钢铁加工线解锁 | 120 | 50 |
| 修复剂 | 5mm激光沉积修复剂 | 基础配额 | 120 | 50 |
| 修复剂 | 25mm激光沉积修复剂 | 基础配额 | 280 | 120 |
| 工业品 | 钢锭 | 钢铁加工线解锁 | 80 | 35 |
| 工业品 | 铜线 | 铜铝加工线解锁 | 120 | 55 |
| 稀有材料 | 辉锗晶体 | 辉锗矿脉解锁 | 2000 | 800 |

#### 7.2.3 价格波动机制

交易终端价格随以下因素波动：

| 因素 | 波动范围 | 触发条件 |
|------|----------|----------|
| 开发进度 | -20% ~ +10% | 对应开发节点进度达50%/100% |
| 物流状态 | +10% ~ +50% | 对应物流线中断 |
| 供应充足度 | -10% ~ +20% | 基地该物资库存变化 |
| 时间衰减 | -5% ~ +5% | 长期无人交易自动调整 |

**价格波动示例**：
- 钢铁加工线解锁100% → 钢锭终端价从80降至64（-20%）
- 2号物流线中断 → 铜矿石终端价从6升至9（+50%）
- 基地钢锭库存达上限 → 钢锭终端收购价从35降至30

### 7.3 NPC小贩

#### 7.3.1 小贩定位

NPC小贩为个体小批量交易提供渠道，价格波动更灵活，物资更丰富（包括部分非合规物资）。

**小贩生成逻辑**：
- 小贩由NPC系统生成，当前为简化实现
- 每个小贩携带少量随机物资，或按类型配置
- 小贩位置不固定，会在基地与地图各地点移动

#### 7.3.2 小贩物资与定价

| 小贩类型 | 专营物资 | 定价逻辑 |
|----------|----------|----------|
| 矿工小贩 | 矿产、矿石 | 略低于交易终端收购价 |
| 军需小贩 | 弹药、修复剂 | 略高于交易终端售价 |
| 黑市小贩 | 稀有材料、外星部件 | 价格波动大，无监管 |
| 拾荒小贩 | 回收材料、残骸物资 | 固定低价 |

#### 7.3.3 小贩交易流程

```
1. 玩家在地图或基地找到小贩
   ↓
2. 与小贩交谈
   ↓
3. 小贩展示携带的物资与报价
   ↓
4. 玩家选择购买或出售
   ├── 购买：按小贩报价支付信用点
   └── 出售：按小贩报价获得信用点
   ↓
5. 交易完成
```

### 8.1 核心循环

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │

│  [更大规模生产] ──→ [更高信用点收益] ──→ [循环]                    │

└─────────────────────────────────────────────────────────────────────┘
```

### 8.2 经济体系层次

| 层次 | 机制 | 意识形态表达 |
|------|------|--------------|
| **主导层** | 开发树 + 供需清单 + 配额制 | 计划经济、组织性、按需分配 |
| **补充层** | 交易终端 + NPC小贩 | 市场调节、自由交易 |
| **保障层** | 基础配额 + 物流维护 | 集体保障、互助协作 |

### 8.3 玩家体验路径

| 游戏阶段 | 核心活动 | 经济系统参与 |
|----------|----------|--------------|
| 初期（0-5游戏天） | 探索、采集、小型生产 | 交付基础物资获取信用点，解锁第一层开发节点 |
| 中期（5-20游戏天） | 建造生产线、维护物流、扩大生产 | 持续交付工业品推进第二层开发节点，解锁基础载具 |
| 后期（20游戏天+） | 供应链补全、关键事件、装备升级 | 触发第三层装备解锁，按需领取高级载具 |

### 9.2 核心计算

#### 9.2.1 开发进度计算

```javascript
function calculateProgress(itemId, quantity) {
  const item = supplyDemandList.find(i => i.id === itemId);
  if (!item || !item.progressNode) return null;

  const node = developmentTree.find(n => n.id === item.progressNode);
  if (!node || node.unlocked) return null;

  const progressGain = quantity;  // 每单位推进1点
  const newProgress = Math.min(node.progress + progressGain, node.maxProgress);
  const unlocked = newProgress >= node.maxProgress;

  return {
    nodeId: node.id,
    progress: newProgress,
    progressGain: progressGain * 0.3,  // 玩家贡献占30%，NPC占70%
    npcContribution: progressGain * 0.7,
    unlocked: unlocked
  };
}
```

#### 9.2.2 价格波动计算

```javascript
function calculateTerminalPrice(basePrice, factors) {
  let price = basePrice;

  // 开发进度影响
  if (factors.developmentProgress >= 1) {
    price *= 0.8;  // 解锁后降价20%
  } else if (factors.developmentProgress >= 0.5) {
    price *= 0.9;  // 进度达50%降价10%
  }

  // 物流状态影响
  if (factors.logisticsInterrupted) {
    price *= 1.5;  // 物流中断涨价50%
  }

  // 供应充足度影响
  if (factors.supplyLevel < 0.3) {
    price *= 1.2;  // 供应不足涨价20%
  } else if (factors.supplyLevel > 0.9) {
    price *= 0.9;  // 供应充足降价10%
  }

  return Math.round(price);
}
```

#### 9.2.3 配额检查

```javascript
function checkQuota(type, itemId, player) {
  const now = Date.now();
  const quotas = player.quotas[type];

  if (type === 'basic') {
    // 基础配额：每日重置
    const dailyQuota = quotas.find(q => q.date === getToday());
    const itemQuota = dailyQuota.items.find(i => i.id === itemId);
    return itemQuota ? itemQuota.remaining : 0;
  } else if (type === 'advanced') {
    // 高级配额：按需领取
    const itemQuota = quotas.find(q => q.itemId === itemId);
    if (!itemQuota || !itemQuota.unlocked) return 0;

    if (itemQuota.type === 'vehicle') {
      return player.hasVehicle(itemId) ? 0 : 1;  // 载具：损毁/未持有可领
    } else {
      return itemQuota.remaining;  // 材料：按配额
    }
  }
}
```

## 10 小结

本设计书定义了织女-7先遣星球的完整经济系统，核心框架包括：

1. **信用点体系**：通用可流通货币，降低理解门槛
2. **三层开发树**：原材料→工业品→装备成品，每层解锁逻辑不同
3. **供需清单**：基地常驻收购，玩家随时交付换取信用点
4. **自动化制造**：生产线建成后持续产出，玩家关注战略决策
5. **物流系统**：半显性、有风险的连接系统，需玩家维护
6. **双轨配额制**：基础配额保障日常，高级配额成就驱动
7. **混合市场**：交易终端（机构化）+ NPC小贩（自由化）

经济系统通过"硬灌输不如软渗透"的策略，将社会主义意识形态融入游戏机制：
- 组织性：玩家天然处于基地组织中，经济活动服务于星球开发
- 计划性：开发树体现有规划的发展路径，而非无序市场
- 按需分配：配额制体现"各取所需"原则
- 劳动价值：信用点来自生产劳动，而非投机倒把
- 互助协作：物流维护、供应链补全体现共同体精神
