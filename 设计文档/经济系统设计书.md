# 经济系统设计书

## 1 概述

### 1.1 设计目标

本文档定义织女-7先遣星球上的经济系统，涵盖信用点体系、供销机制、配额制、本地市场与价格波动。经济系统负责"物资怎么交易"、"玩家如何获取经济回报"、"价格如何波动"，是连接 [物品设计书](file:///workspace/设计文档/物品设计书.md)、[装备系统设计书](file:///workspace/设计文档/装备系统设计书.md)、[制造建造系统设计书](file:///workspace/设计文档/制造建造系统设计书.md) 的核心流通枢纽。

经济系统设计遵循以下原则：

- **交易驱动**：经济系统的核心是交易与流通，"能不能生产"由制造建造系统决定，"怎么交易"由经济系统决定。
- **价格动态**：物资价格随制造建造系统的开发进度、物流状态、库存水平动态波动，体现供需关系。
- **双轨分配**：基础配额保障日常战斗消耗（集体保障），高级配额按需解锁（按需分配），交易终端与可交易NPC提供市场补充（自由调剂）。
- **隐蔽的意识形态**：采用通用货币体系降低理解门槛，通过"跟着基地计划走收益最稳定"的体验，自然传递组织性与计划性的价值。

### 1.2 社会主义意识形态的表达

本经济系统在设计上融入社会主义意识形态的核心要素，但以游戏机制的方式自然呈现：

| 要素 | 游戏机制体现 | 体验表达 |
|------|--------------|----------|
| 计划与组织 | 供需清单（基地发布需求）、开发进度影响价格（计划性传导至市场） | 玩家感受到"为整体目标而生产"，价格随计划推进而下降 |
| 集体利益 | 交付物资推进开发进度（所有玩家贡献累积推进基地发展） | 玩家的生产活动直接推动基地升级，产生集体荣誉感 |
| 按需分配 | 配额制（基础保障+高级按需领取） | 体现"各取所需"的分配原则，高级配额按需解锁 |
| 劳动价值 | 信用点来自交付物资（劳动产出），而非投机倒把 | 玩家通过生产劳动获得回报，而非资本积累 |
| 互助协作 | 物流维护影响价格（共同维护物流线降低 everyone's 成本） | 玩家的生产活动互相支撑，体现共同体精神 |

### 1.3 核心框架

经济系统由以下核心机制构成：

```
┌─────────────────────────────────────────────────────────────┐
│                        经济系统核心循环                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  玩家获得物资 ──→ 交付供需清单 ──→ 获得信用点 + 推进开发进度 │
│       ↑                                              ↓       │
│       │                                       制造建造系统   │
│       │                                              ↓       │
│       │                                       开发节点解锁   │
│       │                                              ↓       │
│       │                                       物资/配额开放  │
│       │                                              ↓       │
│       └────────── 信用点 → 交易终端 / 可交易NPC ───────┘       │
│                      ↓                                      │
│              配额制 → 免费补给 / 按需领取                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.5 与制造建造系统的接口

经济系统不拥有开发树，而是**消费制造建造系统的状态**。两者的接口如下：

| 接口方向 | 内容 | 说明 |
|----------|------|------|
| 经济系统 → 制造建造系统 | 物资交付推进 | 玩家向供需清单交付物资时，经济系统调用制造建造系统计算并推进开发进度 |
| 制造建造系统 → 经济系统 | 开发节点状态通知 | 节点解锁时，制造建造系统通知经济系统更新供需清单、解锁配额、上架交易终端物资 |
| 制造建造系统 → 经济系统 | 物流线状态通知 | 物流线中断/恢复时，制造建造系统通知经济系统调整对应物资价格 |
| 制造建造系统 → 经济系统 | 设施产出入库 | 设施产出的物资自动存入基地仓库，经济系统据此更新库存与价格 |

> 经济系统通过调用制造建造系统的状态查询接口（如"某节点是否已解锁""某物流线是否中断"）来决定物资是否可交易、价格如何波动。制造建造系统的具体设计见 [制造建造系统设计书](file:///workspace/设计文档/制造建造系统设计书.md)。

## 2 核心概念

### 2.1 信用点（CR）

信用点是织女-7先遣星球的通用货币，用于所有经济活动的计价与交易。

| 属性 | 说明 |
|------|------|
| 获取方式 | 向基地供需清单交付物资、完成任务奖励、可交易NPC交易 |
| 使用场景 | 交易终端采购、配额商店购买、可交易NPC交易 |
| 流通范围 | 基地内所有交易终端、可交易NPC、玩家间（未来联机） |
| 价值锚定 | 与基地供需清单的收购价挂钩，避免恶性通胀 |

**信用点获取示例**：

| 物资 | 交付数量 | 获得信用点 |
|------|----------|-----------|
| 铁矿石（MIN001） | 100单位 | 500 CR |
| 钢锭（REF002） | 50单位 | 2000 CR |
| 75mm炮弹（AMM001） | 10单位 | 500 CR |

### 2.2 供需清单

供需清单是基地常驻的物资收购与销售清单，是经济循环的核心接口。

#### 2.2.1 需求清单（收购）

基地发布的物资收购清单，玩家可随时交付物资换取信用点。交付的物资同时通过接口调用推进制造建造系统的开发进度。

**需求清单位置**：基地交易终端的"供销窗口"

**需求清单格式**：

| 物资类别 | 物资名称 | 收购价（CR/单位） | 关联开发节点 | 备注 |
|----------|----------|-------------------|-------------|------|
| 矿产 | 铁矿石（MIN001） | 5 | 铁矿脉群 | 基础原料，不限量 |
| 矿产 | 铁氧体（MIN002） | 8 | 铁矿脉群 | 高阶原料，不限量 |
| 矿产 | 铜矿石（MIN003） | 6 | 铜矿脉群 | 基础原料，不限量 |
| ... | ... | ... | ... | ... |
| 提炼产物 | 钢锭（REF002） | 40 | 钢铁加工线 | 工业品，不限量 |
| 弹药 | 75mm炮弹（AMM001） | 50 | 基础载具供应 | 弹药，不限量 |

#### 2.2.2 销售清单（采购）

基地配额商店与交易终端的物资销售清单，物资的**解锁状态由制造建造系统的开发树决定**。

**配额商店**：仅解锁配额的物资可领取，按需领取，价格远低于市场。

**交易终端**：所有已解锁的物资均可购买，价格接近收购价的2-3倍。

**销售清单格式**：

| 物资名称 | 配额商店价（CR） | 交易终端价（CR） | 解锁条件 |
|----------|------------------|------------------|----------|
| 75mm炮弹（AMM001） | 30 | 80 | 钢铁加工线解锁 |
| 5mm激光沉积结构修复剂（POT001） | 50 | 120 | 基础配额 |
| 25mm激光沉积结构修复剂（POT002） | 100 | 250 | 基础配额 |
| 基础载具组件 | 按需领取 | 20000 | 基础载具供应解锁 |
| 高级载具组件 | 按需领取 | 80000 | 高级载具供应解锁 |

### 2.3 交付机制

玩家向供需清单交付物资的流程：

```
1. 玩家选择交付物资
   ↓
2. 系统检查物资是否在需求清单中
   ├── 是 → 显示收购价
   └── 否 → 提示"该物资暂不在收购清单中，可前往可交易NPC尝试出售"
   ↓
3. 玩家确认交付数量
   ↓
4. 系统执行交付
   ├── 扣除玩家物资
   ├── 增加玩家信用点
   └── 调用制造建造系统接口，推进对应开发节点进度
   ↓
5. 显示交付结果（获得信用点）
```

### 2.4 信用点计算

交付物资获得的信用点按以下公式计算：

```
获得信用点 = 物资数量 × 收购价
```

**示例**：
- 交付100单位铁矿石：100 × 5 = 500 CR
- 交付50单位钢锭：50 × 40 = 2000 CR

## 3 配额制

### 3.1 配额制定位

配额制是经济系统的保障与激励机制，体现"按需分配"原则。

**配额制特点**：
- **基础配额**：保障日常战斗消耗，免费供应
- **高级配额**：成就驱动，按需领取，体现"各取所需"

### 3.2 基础配额

#### 3.2.1 配额内容

基础配额包括日常战斗所需的弹药与修复剂，在机库维修站可免费补给。

| 配额物资 | 每日配额 | 获取方式 |
|----------|----------|----------|
| 75mm炮弹（AMM001） | 30发 | 机库维修站免费补给 |
| 105mm炮弹（AMM002） | 20发 | 机库维修站免费补给 |
| 5mm激光沉积结构修复剂（POT001） | 5个 | 机库维修站免费补给 |
| 25mm激光沉积结构修复剂（POT002） | 3个 | 机库维修站免费补给 |
| 8μm等离子喷涂装甲修复剂（POT004） | 3个 | 机库维修站免费补给 |

#### 3.2.2 配额使用

**补给流程**：
```
1. 玩家进入机库维修站
   ↓
2. 点击"补充补给"
   ↓
3. 系统检查当日剩余配额
   ├── 配额充足 → 免费补给对应物资
   ├── 配额不足 → 提示"今日配额已用完，超出部分需消耗信用点购买"
   │   └── 玩家确认 → 按交易终端价购买
   └── 已超出 → 直接按交易终端价购买
   ↓
4. 显示补给结果（免费部分 + 付费部分）
```

**配额重置**：
- 每日零点（游戏内时间）重置基础配额
- 未使用的配额不累积至次日

### 3.3 高级配额

#### 3.3.1 配额内容

高级配额为载具与稀有装备，按需领取，需通过制造建造系统的开发树节点解锁。

**可解锁配额（示例）**：

| 配额类别 | 具体物资 | 解锁条件（制造建造系统） | 领取方式 |
|----------|----------|------------------------|----------|
| 基础载具 | 轻型侦察车 | 开发树"基础载具供应"节点解锁 | 载具损毁后按需领取 |
| 基础载具 | 中型运输车 | 开发树"基础载具供应"节点解锁 | 载具损毁后按需领取 |
| 高级载具 | 重型战斗车 | 开发树"高级载具供应"节点解锁 | 载具损毁后按需领取 |
| 高级载具 | 离子炮载具 | 开发树"高级载具供应"节点解锁 | 载具损毁后按需领取 |
| 传奇载具 | 反物质发生器 | 开发树"传奇载具供应"节点解锁 | 载具损毁后按需领取 |
| 稀有材料 | 辉锗晶体 | 完成"辉锗矿脉占领"成就 | 按需领取 |

#### 3.3.2 配额解锁方式

高级配额的解锁由制造建造系统驱动：

| 解锁方式 | 示例 |
|----------|------|
| 开发树节点解锁 | 制造建造系统解锁"基础载具供应"节点 → 经济系统开放基础载具配额 |
| 关键事件触发 | 遭遇巨型守卫虫，制造建造系统解锁重型战斗车供应 → 经济系统开放配额 |
| 任务完成 | 完成"辉锗矿脉清剿"任务 → 经济系统开放辉锗晶体配额 |
| 成就达成 | 累计交付1000单位钛锭 → 经济系统开放钛合金载具配额 |

#### 3.3.3 配额领取

**按需领取机制**：
- 载具配额：当前无该类型载具（已损毁或未持有）时可领取
- 材料配额：随时可领取，但领取后从配额中扣除

**领取流程**：
```
1. 玩家打开"配额商店"
   ↓
2. 系统查询制造建造系统，获取已解锁的开发节点列表
   ↓
3. 显示已解锁的高级配额
   ↓
4. 选择要领取的配额物资
   ↓
5. 系统检查领取条件
   ├── 载具：当前是否持有该类型载具
   ├── 材料：当前配额是否充足
   └── 制造建造系统供应链：对应开发节点是否已解锁、物流线是否未中断
   ↓
6. 条件满足 → 免费领取
   条件不满足 → 提示原因
```

#### 3.3.4 配额奖励选择

部分高级配额解锁时，玩家可在多个选项中选择一项解锁：

**示例**：
> 恭喜！制造建造系统已解锁"高级载具供应"节点。请选择一项解锁：
> - A. 重型战斗车配额
> - B. 离子炮载具配额
> - C. 反物质发生器配额（需额外完成"反物质前体交付"成就）

## 4 本地市场

### 4.1 本地市场定位

本地市场是基地供销体系的补充，提供计划外的物资调剂渠道。

**本地市场特点**：
- **交易终端**：机构化大宗贸易，合规物资，供需定价
- **可交易NPC**：基于标签的个体小批量交易，价格波动

### 4.2 交易终端

#### 4.2.1 终端定位

交易终端代表基地监管下的合规大宗贸易，是本地市场的主要交易场所。

**交易终端位置**：基地中央交易大厅

**交易终端功能**：
- 出售已解锁的合规物资（价格为收购价的2-3倍）
- 收购玩家的多余物资（价格略低于供需清单收购价）

> 物资的"已解锁"状态由制造建造系统的开发树节点状态决定。

#### 4.2.2 终端物资清单

交易终端的物资清单随制造建造系统的开发树进度解锁：

| 物资类别 | 可交易物资 | 解锁条件 | 终端售价（CR） | 终端收购价（CR） |
|----------|-----------|----------|---------------|-----------------|
| 弹药 | 75mm炮弹 | 钢铁加工线解锁 | 80 | 30 |
| 弹药 | 105mm炮弹 | 钢铁加工线解锁 | 120 | 50 |
| 修复剂 | 5mm激光沉积修复剂 | 基础配额 | 120 | 50 |
| 修复剂 | 25mm激光沉积修复剂 | 基础配额 | 280 | 120 |
| 工业品 | 钢锭 | 钢铁加工线解锁 | 80 | 35 |
| 工业品 | 铜线 | 铜铝加工线解锁 | 120 | 55 |
| 稀有材料 | 辉锗晶体 | 辉锗矿脉解锁 | 2000 | 800 |

#### 4.2.3 价格波动机制

交易终端价格随以下因素波动，其中**开发进度与物流状态需查询制造建造系统**：

| 因素 | 波动范围 | 触发条件 | 数据来源 |
|------|----------|----------|----------|
| 开发进度 | -20% ~ +10% | 对应开发节点进度达50%/100% | 制造建造系统 |
| 物流状态 | +10% ~ +50% | 对应物流线中断 | 制造建造系统 |
| 供应充足度 | -10% ~ +20% | 基地该物资库存变化 | 经济系统自身 |
| 时间衰减 | -5% ~ +5% | 长期无人交易自动调整 | 经济系统自身 |

**价格波动示例**：
- 制造建造系统解锁钢铁加工线100% → 钢锭终端价从80降至64（-20%）
- 制造建造系统报告2号物流线中断 → 铜矿石终端价从6升至9（+50%）
- 基地钢锭库存达上限 → 钢锭终端收购价从35降至30

### 4.3 可交易NPC

#### 4.3.1 定位

本地市场中除了机构化的交易终端外，还存在一类可交易NPC。这些NPC并非专职商人，而是星球上各类身份的角色（如矿工、军需官、拾荒者、情报贩子等），他们基于自身身份携带少量物资，玩家可以与他们进行小批量交易。

**特点**：
- **非专职**：这些NPC有各自的身份与功能（如发布任务、提供情报、承载随机事件），交易只是其附带功能之一
- **标签驱动**：NPC携带的交易物资由其身份标签决定，如"矿工"标签的NPC会携带少量矿产，"军需官"标签的NPC会携带弹药与修复剂
- **价格浮动**：NPC的报价参照交易终端价格波动机制，但带有个人化差异
- **物资有限**：每个NPC携带的物资数量较少，交易完即售罄

#### 4.3.2 标签与交易物资

NPC的交易物资由其身份标签决定，以下为示例对应关系：

| NPC标签 | 携带物资类型 | 定价倾向 |
|---------|-------------|----------|
| 矿工 | 矿产、矿石 | 略低于交易终端收购价（同行互通有无） |
| 军需官 | 弹药、修复剂 | 接近交易终端售价（官方指导价） |
| 拾荒者 | 回收材料、残骸物资 | 固定低价（急于脱手） |
| 情报贩子 | 稀有材料、外星部件 | 价格波动大（看人报价） |
| 运输司机 | 燃料、工业原料 | 略低于终端价（夹带私货） |

> 以上为示例，实际NPC标签与交易物资由NPC系统定义，经济系统仅读取标签决定可交易物资范围。

#### 4.3.3 交易流程

```
1. 玩家在地图或基地遇到NPC
   ↓
2. 与NPC交谈，选择"交易"选项
   ↓
3. 系统根据NPC标签生成该NPC的可交易物资与报价
   ↓
4. 玩家选择购买或出售
   ├── 购买：按NPC报价支付信用点
   └── 出售：按NPC报价获得信用点
   ↓
5. 交易完成，NPC物资库存扣减
```

#### 4.3.4 与NPC系统的关系

可交易NPC的生成、移动、任务承载等行为由NPC系统统一管理，经济系统仅负责：
- 根据NPC标签查询对应的交易物资表
- 结合价格波动机制计算NPC的当前报价
- 执行交易并扣减/增加物资与信用点

NPC系统的具体设计将在NPC系统设计书中定义。

## 6 技术实现要点

### 6.1 核心数据属性

#### 6.1.1 供需清单条目

供需清单条目定义基地收购与销售的具体物资信息：

| 属性 | 用途 |
|------|------|
| 物资ID | 关联物品设计书中的物品唯一标识 |
| 物资名称 | 清单中显示的名称 |
| 分类 | 物资所属的物品大类（矿产/提炼产物/工业品/弹药等），用于清单分组显示 |
| 收购价 | 基地供需清单的收购价格，玩家交付物资时按此价格计算信用点 |
| 终端售价 | 交易终端的销售价格，通常为收购价的2-3倍 |
| 终端收购价 | 交易终端的收购价格，略低于供需清单收购价，促使玩家优先走供销渠道 |
| 关联开发节点 | 标记交付该物资时推进哪个开发树节点（制造建造系统），为空则不推进进度 |
| 是否已解锁 | 标记该物资是否已在交易终端上架，取决于制造建造系统的开发树节点状态 |

#### 6.1.2 配额记录

配额记录跟踪玩家的基础配额与高级配额状态：

| 属性 | 用途 |
|------|------|
| 配额类型 | 区分基础配额/高级配额 |
| 物资ID | 配额对应的物资唯一标识 |
| 日期 | 基础配额的生效日期（每日重置） |
| 剩余数量 | 当日/当前剩余可领取数量 |
| 是否已解锁 | 高级配额是否已解锁，取决于制造建造系统的开发树节点状态 |
| 配额类别 | 载具/材料，决定领取条件（载具需检查当前持有状态） |

### 6.2 核心计算逻辑

#### 6.2.1 价格波动计算

交易终端的物资价格需要根据世界状态动态调整，计算逻辑如下：

1. **基础价格**：取该物资在供需清单中的终端售价作为基准。
2. **开发进度修正**：查询制造建造系统，获取该物资关联的开发节点进度。若节点已完全解锁，价格下调20%；若进度达50%，价格下调10%。
3. **物流状态修正**：查询制造建造系统，获取该物资关联的物流线运行状态。若物流线处于中断或受阻状态，价格上浮50%。
4. **库存修正**：查询经济系统自身的基地仓库库存水平。库存低于30%时价格上浮20%；库存高于90%时价格下调10%。
5. **时间衰减修正**：长期无人交易的物资，价格自动微调±5%，模拟市场缓慢调节。
6. **最终价格**：将以上修正系数依次相乘后取整，得到最终终端价格。

#### 6.2.2 配额检查

配额检查分为基础配额与高级配额两条逻辑：

**基础配额**：
1. 根据当前游戏内日期查找当日配额记录。
2. 查找目标物资在当日配额中的剩余数量。
3. 若剩余数量大于0，玩家可免费补给，补给后扣减剩余数量。
4. 若剩余数量为0，提示配额已用完，后续补给按交易终端价收费。
5. 每日零点重置所有基础配额的剩余数量，未使用部分不累积。

**高级配额**：
1. 查询制造建造系统，确认目标物资对应的开发节点是否已解锁。
2. 若未解锁，返回不可领取。
3. 若已解锁，继续检查：
   - 载具类配额：检查玩家当前是否持有该类型载具——未持有时可领取（载具损毁或从未获取），领取后配额标记为已使用。
   - 材料类配额：检查剩余领取次数，大于0时可领取，领取后扣减。
4. 额外查询制造建造系统，确认对应供应链是否正常运行（物流线是否未中断），供应链异常时无法领取。

## 8 小结

本设计书定义了织女-7先遣星球的经济系统，核心框架包括：

1. **信用点体系**：通用可流通货币，降低理解门槛
2. **供销机制**：供需清单（收购/销售）、交付机制、信用点计算
3. **双轨配额制**：基础配额保障日常，高级配额成就驱动、按需领取
4. **混合市场**：交易终端（机构化大宗）+ 可交易NPC（标签驱动个体交易）
5. **价格波动**：结合制造建造系统的开发进度与物流状态，动态调整终端价格

经济系统与 [制造建造系统设计书](file:///workspace/设计文档/制造建造系统设计书.md) 紧密耦合但职责分明：经济系统管"怎么交易"，制造建造系统管"能不能生产"。两者通过清晰的接口对接——经济系统消费制造建造系统的开发树状态来决定物资交易与配额开放，共同构成完整的星球资源开发与流通体系。

经济系统通过"硬灌输不如软渗透"的策略，将社会主义意识形态融入游戏机制：
- 组织性：玩家天然处于基地组织中，经济活动服务于星球开发
- 计划性：价格随制造建造系统的开发进度波动，计划推进降低成本
- 按需分配：配额制体现"各取所需"原则
- 劳动价值：信用点来自生产劳动，而非投机倒把
- 互助协作：共同维护物流线降低所有人的采购成本
