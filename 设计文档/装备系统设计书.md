# 装备系统设计书

## 概述

### 游戏背景（装备相关）

未来人类掌握了受限虫洞跳跃技术，传送物品的质量上限约为2千克。一个成年人类大脑的物理质量约为1.4千克，恰好落在这个质量窗口之内——这让人类想起了那个古老的寓言：只送大脑。

人类已将人脑意识上传到电子脑中。电子脑的物理质量严格控制在800克以下，远低于2千克的虫洞承载极限。配合超轻型的探测器躯壳，先遣队员被一批批送往外星球，指挥微型机器人建立工业体系。

由于虫洞无法传送成品载具，所有战斗载具都必须在目标星球上利用当地资源建造。这直接塑造了装备系统的设计逻辑：装备和载具高度模块化，依赖本地工业体系，资源管理是核心玩法之一。

### 装备系统概述

玩家扮演的本质是数字生命，本体是那颗电子脑，电子脑放置于载具之中。载具提供了角色战斗、生活的必要属性，包括运动能力、结构值、装甲、接口（装备栏位）、装备舱、货舱、重量等。

装备系统设计遵循以下原则：

- 所有装备必须通过接口安装到载具上，接口类型和属性必须满足装备的接口需求。
- 载具的总功率和算力是硬性预算，所有装备的运行需求之和不得超过总功率。
- 资源点数（能量、离子、燃料、弹药）由载具上的容器和生成器提供，是武器开火和装备运转的消耗品。
- 同一装备存在数值浮动和品质差异，词缀系统为装备提供额外的随机属性。

### 经济成长

游戏中存在不同档次、强度的装备、机体、载具。获取装备的途径主要包括：

- **任务奖励**：完成星发委发布的任务可获得特定装备蓝图或成品。
- **制造系统**：利用工业设施按照蓝图消耗资源制造装备。制造成功率受工艺技能等级影响。
- **经济交易**：与其他先遣队员或据点商人进行装备买卖。经济系统采用资源本位货币。
- **战利品**：击败敌人后从其残骸中打捞未损坏的装备。叛军载具掉落的装备通常品质较高。
- **改装升级**：在已有装备基础上进行改装，消耗偏差值和材料提升性能或增加特殊效果。

## 载具系统

### 载具类型

| 类型 | 特征 | 适用场景 |
|------|------|---------|
| **机体** | 人形载具，重量轻、灵活性高，主要用于城市建设场景，也有适配战斗的型号 | 近距离巡逻、据点内部作业 |
| **机甲** | 足式载具，通过性强、加速度高，能够适应崎岖地形 | 复杂地形作战、山地/峡谷区域 |
| **战车** | 轮履载具，平坦地形极限速度高，可搭载更重的装甲和火力 | 开阔地带突击、火力支援 |
| **飞行器** | 飞船、飞机等，提供侦察和快速机动能力 | 侦察、快速转移、空中支援 |

载具主要通过功率、算力和接口数量进行平衡。越大越昂贵的载具，提供的功能就越多，但运动能力会下降。运动能力细分如下：

- **轮式载具**：平坦地面速度最高，但碎石、沙地等粗糙地形的速度惩罚很重。
- **履带载具**：通过性更高，地形惩罚较小，但极限速度低于轮式。
- **足式载具**：适应性最好，加速度最高，但载重能力最低。

### 载具属性

| 属性 | 含义 | 说明 |
|------|------|------|
| 结构值 | 载具本体耐久度 | 整数，归零则机体损毁 |
| 装甲值 | 外部装甲层提供的防护 | 优先于结构值被消耗 |
| 速度 | 平坦地面的移动速率 | 米/秒，受地形惩罚修正 |
| 功率 | 支持设备运行的能源输出 | 单位kW，所有装备的运行需求之和不得超过总功率 |
| 算力 | 核心计算机的数据处理能力 | 单位MFlops，影响瞄准、电子战、队友数量上限 |
| 接口 | 装备安装的槽位 | 具有类型和属性，决定可安装的装备种类 |
| 装备舱 | 可容纳的装备总重量 | 决定载具可携带装备的上限 |
| 货舱 | 可容纳的货物总重量 | 决定可携带的资源和物品上限 |
| 重量 | 载具自身质量 | 影响加速度和部分地形的通过能力 |

### 接口系统

接口是装备与载具之间的连接点，每个接口具有类型和属性。装备必须满足接口的类型和属性需求才能安装。

| 接口属性 | 说明 | 适用装备 |
|---------|------|---------|
| **外部** | 接口位于载具外部，暴露在环境中 | 炮台、探测装备、装甲板 |
| **电源** | 可提供一定功率的电源输出 | 所有需要功率的装备 |
| **管道** | 提供一定通量的流体传输能力，具有温度属性 | 燃料供给、冷却系统、离子输送 |
| **数据** | 提供数据通信线路，单位是带宽 | 需要算力的装备、火控系统、传感器 |
| **界面** | 决定接口可装备的装备体积上限 | 所有需要占用空间的装备 |

**管道细分类型**：常温流体管道、离子管道、高温管道、特殊管道（反物质传输）。装备对管道类型有明确需求，类型不匹配则无法安装。

### 核心舱

核心舱位于载具中心，包含以下关键模块：

- **核心计算机**：提供算力（MFlops），影响武器瞄准速度、电子战成功率、队友控制数量上限。可替换升级。
- **核心动力**：提供输出功率（kW），本质是一个功率输出总线接口。所有装备的运行需求功率之和不得超过核心动力的总输出功率。
- **接驳模块**：放置玩家电子脑的位置，决定电子脑的物理接口。玩家可改造接驳模块，增加逃生舱等功能——逃生舱可在机体损毁前自动弹射电子脑，降低死亡时的装备损失。

**硬性约束**：载具必须安装核心计算机和核心动力，缺少任一模块载具无法使用。拆除这些模块的载具会被系统标注为"核心缺失"。

### 载具自带功能

部分载具可自带一些装备功能，不占用额外接口：

- **电容器**：直接提供能量资源点数，可用于激光炮、电磁炮等高功率武器。
- **离子生成器**：直接提供离子资源点数，用于离子炮和部分反应堆。
- **燃料箱**：提供燃料资源点数，用于内燃机和火焰喷射器。

自带功能的资源点数上限和恢复速度取决于载具型号，不可改装。

### 运动能力

运动能力由载具类型和配置共同决定：

- **基础速度**：载具在平坦地面的移动速度，单位米/秒。
- **加速度**：从静止到全速所需的时间，足式载具最高，轮式次之，履带最低。
- **转向速度**：载具改变行进方向的能力，足式和机体最高，战车最低。
- **地形适应性**：不同地形对速度的影响系数，由载具底盘类型决定。

## 资源点数

资源点数是载具上各类消耗性资源的统称，类比于传统RPG中的MP。资源点数由容器和生成器提供，被武器和装备消耗。

| 资源类型 | 来源 | 主要用途 | 恢复方式 |
|---------|------|---------|---------|
| **能量** | 电容器 | 激光炮、电磁炮、护盾维持、电子战设备 | 能量生成器、太阳能板、反应堆 |
| **离子** | 离子容器 | 离子炮发射、部分反应堆运转、结构修复 | 离子发生器 |
| **燃料** | 油箱 | 内燃机、发电机、火焰喷射器 | 炼油设施加工碳氢原料 |
| **弹药** | 弹舱 | 火炮、电磁炮、导弹/火箭 | 自动装弹机（消耗货舱中的弹药原料） |
| **反物质** | 反物质容器 | 高端武器、高级反应堆 | 反物质发生器（后期装备） |

资源点数的恢复方式：

- 部分装备（如能量生成器、离子发生器）可持续恢复对应资源点数，消耗功率。
- 部分恢复装备会消耗货舱中的原材料，如自动装弹机向弹舱补充弹药时，消耗货舱中的弹药原料。
- 资源点数在脱离战斗状态后，可通过载具自带的资源回收系统进行基础恢复（效率较低）。

## 装备分类

### 武器

| 武器类型 | 工作原理 | 接口需求 | 资源消耗 | 射程 | 优点 | 缺点 |
|---------|---------|---------|---------|------|------|------|
| **火炮** | 火药发射炮弹 | 外部、弹药管道、数据、电源 | 弹药 | 中程至远程(50-600m) | 弹药消耗稳定，单发伤害高，不依赖电容器 | 有飞行时间需预判，需持续补给弹药 |
| **电磁炮** | 磁轨加速弹丸 | 外部、弹药管道、数据、电源 | 能量+弹药 | 中程至远程(100-800m) | 弹速极高，远距离精度衰减小，单发伤害极高 | 能量消耗大，连续射击受电容恢复制约，电源需求高 |
| **离子炮** | 发射带电粒子束 | 外部、离子管道、数据、电源 | 离子 | 中程(50-400m) | 电源需求低，对高电子化敌人效果显著 | 不直接造成结构伤害，对虫群等低电子化目标效果极差 |
| **激光炮** | 定向能量束 | 外部、电源、数据 | 能量 | 中程至超远程(50-1000m) | 即时命中无需预判，射程极远，精度衰减小 | 能量消耗极高，持续输出时间短，电源需求大 |
| **导弹/火箭** | 自推进战斗部，追踪或抛物线弹道 | 外部、弹药管道、数据 | 弹药 | 中程至超远程(100-1000m) | 追踪能力命中率高，范围爆炸适合集群目标 | 弹药成本高携行有限，有最低射程限制(30m)，飞行时间可被规避 |
| **近战武器** | 改装的机械臂、切割工具、冲击锤 | 外部、电源、数据 | 能量(少量) | 极近程(0-15m) | 不消耗弹药，攻速快，对装甲破坏显著 | 必须贴近目标，载具承受近身风险 |
| **电子战设备** | 干扰器/入侵模块 | 外部、数据、电源 | 能量 | 中程(50-300m) | 非致命削弱，对叛军尤其有效 | 不直接造成伤害，对无电子系统敌人无效，入侵成功率受算力差距影响 |
| **无人机类武器** | 发射小型自主作战单位 | 外部、数据、电源(部分需弹药管道) | 能量+弹药 | 近程至远程(0-500m) | 攻击灵活，可同时多目标打击，载具保持安全距离 | 占用数据带宽，数量受算力限制，无人机耐久低易被击落 |

### 装甲

| 装甲类型 | 功能 | 接口需求 | 特殊说明 |
|---------|------|---------|---------|
| **装甲板** | 提供装甲值 | 外部 | 基础防护，无额外功能 |
| **内衬装甲** | 提供抗性（如动能抗性、能量抗性） | 内部 | 不增加装甲值，但降低特定伤害类型的穿透效果 |
| **自适应装甲** | 实时分析来袭攻击类型，调整分子排列，对当前伤害类型提供额外15%-30%减免 | 外部、数据、电源 | 切换抗性有短暂延迟(约1秒)，造价昂贵 |

### 护盾

在载具外围生成能量防护场，提供独立于装甲值和结构值的额外防护层。

- 受到攻击时**优先扣除护盾值**。
- 护盾具有自动恢复能力，脱战后每秒恢复一定点数。
- 护盾对不同伤害类型的减免效果不同：动能减免80%，能量减免40%，离子伤害对护盾造成**双倍消耗**。
- 接口需求：外部、电源、数据。
- 资源消耗：能量（维持护盾和吸收攻击均消耗能量）。
- 护盾值上限和恢复速度取决于装备品质和载具功率供给。

### 生成器

| 生成器类型 | 功能 | 接口需求 | 资源消耗 | 说明 |
|-----------|------|---------|---------|------|
| **离子发生器** | 持续将基础物质转化为离子资源 | 离子管道、电源、数据 | 功率 | 产离子速率取决于功率输入和发生器等级 |
| **反物质发生器** | 通过粒子对撞产生微量反物质 | 特殊管道、电源、数据 | 大量功率+少量燃料 | 产率极低，功率需求极高，后期内容 |

### 容器

| 容器类型 | 储存资源 | 说明 |
|---------|---------|------|
| **电容器** | 能量 | 容量决定能量上限，恢复速度决定回能效率 |
| **离子容器** | 离子 | 容量决定离子上限 |
| **油箱** | 燃料 | 容量决定燃料上限 |
| **反物质容器** | 反物质 | 后期容器，容量通常很小但能量密度极高 |

### 修复器

| 修复器类型 | 修复目标 | 接口需求 | 资源消耗 | 说明 |
|-----------|---------|---------|---------|------|
| **装甲修复器** | 装甲值 | 内部、电源、数据 | 货舱金属资源+能量 | 战斗中修复速度降低50%，修复期间无法执行其他动作 |
| **结构修复器** | 结构值 | 内部、电源、数据 | 货舱金属资源+能量+少量离子 | 速度为装甲修复器的60%，战斗中修复速度降至30% |

## 装备属性体系

### 基础属性

所有物品（包括装备和货物）共有的基础属性：

| 属性 | 说明 |
|------|------|
| 重量 | 物品的质量，单位千克。影响载具总重量和加速度。 |
| 类别 | 物品的分类标识（武器、装甲、容器等）。 |
| 货运体积 | 占用货舱的空间大小。 |
| 市场价格 | 在交易系统中出售或购买的基础价格。 |

### 装备属性

装备特有的属性：

| 属性 | 说明 |
|------|------|
| 接口需求 | 安装所需的接口类型和属性（外部/电源/管道/数据/界面）。 |
| 装备体积 | 占用的接口空间，必须与接口的"界面"属性匹配。 |
| 启动需求 | 装备从待机进入可用状态所需的**瞬时功率**，单位kW。功率越富余启动越快。 |
| 运行需求 | 装备保持运行状态**持续消耗**的功率，单位kW。 |
| 运行周期 | 武器的开火间隔或装备的运作周期，单位秒。 |
| 功能 | 装备的核心效果描述（伤害数值、范围、特效等）。 |
| 改装 | 装备可通过改装获得额外能力，改装占用偏差值。 |

### 功率与算力预算系统

**功率预算**：

- 载具的核心动力提供总功率（kW）。
- 所有已安装装备的**运行需求功率之和**不得超过总功率。若超过，系统按以下优先级降级：武器→护盾→电子战→生成器→修复器。
- 装备的**启动需求**是瞬时功率峰值，只要启动瞬间的总功率（已运行装备的运行需求 + 新装备的启动需求）不超过总功率即可启动。
- 功率富余时，富余功率可加速装备启动：启动时间 = 启动需求 / 当前可用功率（秒）。

**算力预算**：

- 核心计算机提供总算力（MFlops）。
- 算力在以下用途中分配：武器瞄准计算、电子战入侵/干扰、队友AI控制、传感器数据处理。
- 当算力不足时，优先级最高的用途优先占用算力，低优先级用途的效率下降。
- 武器开火间隔受算力影响：开火间隔 = 武器运行周期 / (1 + 算力加成)。算力越高，瞄准计算越快，开火越频繁。
- 同时控制的队友数量受算力上限约束：每个队友占用一定带宽，算力不足时无法添加更多队友。

### 装备安装与匹配逻辑

**安装流程**：

1. 选择目标载具上的一个空闲接口。
2. 检查装备的需求是否满足接口类型和属性。
3. 检查功率预算：当前已用运行需求 + 新装备运行需求 <= 总功率。
4. 检查装备舱容量：当前已用装备重量 + 新装备重量 <= 装备舱上限。
5. 检查算力预算：新装备若有数据需求，确认当前算力分配未超限。
6. 全部通过后，装备进入安装状态，经过启动时间后变为可用。

**卸载流程**：

- 卸载装备无冷却，但需要短暂时间（0.5秒）断开接口连接。
- 卸载后装备的功率和算力占用立即释放。
- 核心计算机和核心动力不可卸载。

**接口不匹配情况**：

- 类型不匹配（如需要外部接口但只有内部接口）：无法安装。
- 管道温度不匹配（如需要离子管道但只有常温流体管道）：无法安装。
- 界面空间不足（装备体积 > 接口界面）：无法安装。
- 缺少数据接口但有算力需求：装备可安装但效率降低50%（火控依赖手动瞄准）。

## 装备变量与品质

同一种装备在生成时，其核心数值在基准范围内浮动，形成个体差异。

**品质等级**：

| 品质等级 | 数值浮动范围 | 词缀数量上限 | 偏差值上限 | 颜色标识 |
|---------|------------|------------|----------|---------|
| 普通 | 基准值 x 0.85 ~ 1.0 | 0 | 基准值 x 0 | 白色 |
| 精良 | 基准值 x 0.9 ~ 1.1 | 1 | 基准值 x 1 | 绿色 |
| 稀有 | 基准值 x 0.95 ~ 1.2 | 2 | 基准值 x 2 | 蓝色 |
| 史诗 | 基准值 x 1.0 ~ 1.3 | 3 | 基准值 x 3 | 紫色 |
| 传奇 | 基准值 x 1.1 ~ 1.5 | 4 | 基准值 x 5 | 橙色 |

- 品质在装备生成时确定，越高品质掉落/制造概率越低。
- 偏差值决定装备可通过改装获得的额外能力空间，高品质装备的改装潜力更大。
- 品质不改变接口需求，但高品质装备可能在数值上更高效（同样功率消耗获得更高输出）。

## 装备词缀

### 通用词缀

对所有可拥有词缀的装备生效，影响基础属性或通用战斗数值。

**正面词缀示例**：

| 词缀 | 效果 | 浮动范围 |
|------|------|---------|
| 精准的 | 武器基础命中率 | +5% ~ +15% |
| 稳定的 | 武器暴击率 | +3% ~ +8% |
| 轻量化的 | 装备重量 | -10% ~ -25% |
| 高效的 | 装备运行需求功率 | -5% ~ -15% |
| 强化的 | 装备基础伤害/效果 | +5% ~ +15% |
| 坚固的 | 装备自身耐久 | +20% ~ +50% |
| 快速的 | 装备运行周期 | -5% ~ -15% |

**负面词缀示例**：

| 词缀 | 效果 |
|------|------|
| 笨重的 | 装备重量 +15% ~ +40% |
| 耗能的 | 装备运行需求功率 +10% ~ +30% |
| 不稳定的 | 暴击率 -5%，但基础伤害 +10% |
| 过热的 | 连续使用后积累热量，热量满时需冷却 |
| 粗糙的 | 基础伤害/效果 -5% ~ -15%，但制造成本降低 |

### 特殊词缀

仅对特定类别或特定装备生效，提供该类别特有的特殊效果。

| 词缀 | 限定装备 | 效果 |
|------|---------|------|
| 穿甲的 | 动能武器 | 装甲类型系数 +0.1 ~ +0.2 |
| 过载的 | 能量武器 | 单次伤害 +20% ~ +40%，能量消耗 +30% ~ +50% |
| 追踪的 | 导弹/火箭 | 追踪锁定速度 +20%，目标闪避率对导弹无效 |
| 广域的 | 爆炸武器 | 爆炸半径 +20% ~ +50% |
| 深入侵的 | 电子战设备 | 入侵成功率 +10% ~ +20%，数据带宽需求 +50% |
| 自修复的 | 装甲 | 脱战状态下装甲值每秒自动恢复少量 |
| 反射的 | 护盾 | 吸收的动能伤害有10% ~ 20%概率反弹 |
| 急速充能的 | 电容器 | 能量恢复速度 +15% ~ +30%，总容量 -10% |
| 扩容的 | 各类容器 | 容器容量 +20% ~ +50%，重量 +10% ~ +20% |

**组合规则**：一件装备上的多个词缀不能互相矛盾（如不能同时具有"轻量化的"和"笨重的"）。正面词缀和负面词缀可以同时存在，形成权衡取舍的装备构建。
