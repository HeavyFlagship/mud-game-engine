## 二、模块依赖关系

```mermaid
flowchart TB
    subgraph 基础层
        TS[时间轴系统<br/>游戏时间推进引擎]
        WS[世界观设定<br/>背景与阵营]
    end

    subgraph 数据层
        IT[物品设计书<br/>所有物资ID/属性]
        EN[敌人设计书<br/>敌人与战利品]
    end

    subgraph 核心逻辑层
        subgraph 经济系统
            EC[经济系统设计书<br/>交易/供需/配额]
        end
        subgraph 制造建造
            MF[制造建造系统设计书<br/>开发树/生产/物流]
        end
        subgraph 战斗系统
            BT[战斗系统设计书<br/>战斗规则/时间轴]
        end
        subgraph 装备系统
            EQ[装备系统设计书<br/>载具/装备/词缀]
        end
    end

    subgraph 场景层
        SC[世界场景设计书<br/>地图/场景/据点]
    end

    TS --> BT
    TS --> EC
    TS --> MF
    WS --> SC
    WS --> EN
    IT --> EC
    IT --> MF
    IT --> EQ
    EN --> BT
    EN --> IT
    MF --> EC
    MF --> EQ
    EC --> BT
    EQ --> BT
    SC --> BT
    SC --> EC
```
