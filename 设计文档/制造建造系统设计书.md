# 制造建造系统设计书

## 1 概述

### 1.1 设计目标

本文档定义织女-7先遣星球上的制造与建造系统，涵盖开发树（生产进度控制）、生产设施建造与运行、物流线路建设。制造建造系统是连接 [物品设计书](file:///workspace/设计文档/物品设计书.md)、[世界场景设计书](file:///workspace/设计文档/世界场景设计书.md)、[经济系统设计书](file:///workspace/设计文档/经济系统设计书.md) 的核心枢纽，控制"什么能生产"、"什么能供应"、"怎么运到基地"。

制造建造系统设计遵循以下原则：

- **计划性发展**：通过开发树体现有规划、有依赖的系统性生产发展，玩家需要按顺序解锁原材料产地、加工生产线、装备供应。
- **自动化生产**：设施建成后持续自动产出，玩家精力放在"建什么、建在哪、多大"的决策上，避免枯燥的重复操作。
- **规模弹性**：玩家可根据需求选择小规模（自用）或大规模（补足供应链），生产规模由玩家自主决定。
- **基础设施先行**：物流线、产地解锁是生产的前置条件，体现"要致富先修路"的基础建设逻辑。

### 1.2 核心框架

制造建造系统由以下核心机制构成：

```
┌─────────────────────────────────────────────────────────────┐
│                     制造建造系统核心循环                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  探索/占领产地 → 解锁物流线 → 交付物资推进开发树进度         │
│       ↑                                              ↓       │
│       │                                       开发树节点解锁  │
│       │                                              ↓       │
│       │                                       解锁生产设施    │
│       │                                              ↓       │
│       │                                       建造生产设施    │
│       │                                              ↓       │
│       └────────────── 设施持续产出 ───────────────────┘       │
│                                                             │
│  产出物资 → 存入基地仓库 → 经济系统接管（交易/供需/配额）    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

制造建造系统与经济系统之间通过以下接口对接：

| 制造建造系统 → 经济系统 | 开发树节点状态通知 | 节点解锁时，通知经济系统更新供需清单、解锁配额、上架交易终端物资 |
| 制造建造系统 → 经济系统 | 物流线状态通知 | 物流线中断/恢复时，通知经济系统调整对应物资价格 |

| 经济系统 → 制造建造系统 | 建造物资采购 | 玩家通过经济系统获取建造设施所需的物资 |

## 2 开发树

### 2.1 开发树定位

开发树是制造建造系统的核心进度控制机制，体现先遣基地的有规划、有依赖的系统性发展。它决定：
- 哪些原材料产地已解锁（玩家可去采集）
- 哪些生产设施可以建造
- 哪些装备可以被基地供应

开发树状态是**经济系统**判断物资是否可交易、配额是否可领取的唯一依据。

### 2.2 开发树结构

开发树采用三层结构，对应从原材料到装备成品的完整生产链：

```
┌─────────────────────────────────────────────────────────────────┐
│                        先遣基地开发树                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第一层：原材料供应（产地+物流）                                  │
│  ├── 铁矿脉群 → 物流线①                                        │
│  ├── 铜矿脉群 → 物流线②                                        │
│  ├── 钛矿脉群 → 物流线③                                        │
│  ├── 辉锗矿脉 → 物流线④                                        │
│  ├── 稀土矿脉 → 物流线⑤                                        │
│  └── ...                                                       │
│           ↓                                                     │
│  第二层：工业品加工（生产线）                                    │
│  ├── 钢铁加工线（依赖：铁矿脉群 + 物流线①）                     │
│  ├── 铜铝加工线（依赖：铜矿脉群 + 物流线②）                     │
│  ├── 钛合金加工线（依赖：钛矿脉群 + 物流线③）                   │
│  ├── 电子工业线（依赖：钢铁线 + 铜铝线 + 辉锗矿）               │
│  ├── 稀土加工线（依赖：稀土矿脉 + 物流线⑤）                     │
│  └── ...                                                       │
│           ↓                                                     │
│  第三层：装备成品（关键事件触发）                                │
│  ├── 基础载具供应（依赖：钢铁线 + 铜铝线）                      │
│  ├── 高级载具供应（依赖：钛合金线 + 电子工业线）                │
│  ├── 传奇载具供应（依赖：超导晶格 + 稀土加工线）                │
│  └── ...                                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 三层解锁逻辑

每层的解锁逻辑不同，体现不同生产环节的特点：

| 层级 | 解锁条件 | 玩家参与方式 | NPC并行行为 |
|------|----------|--------------|-------------|
| **原材料供应** | 探索/占领地图产地 + 解锁物流线 | 探索地图、占领矿脉据点、完成物流清障任务 | 其他先遣队员随时间自动解锁部分产地 |
| **工业品加工** | 前置原材料层已解锁 + 玩家建造生产设施 | 在据点建造冶炼炉、化工厂、制造工厂等 | NPC逐步建设基础生产线（钢铁、铜铝） |
| **装备成品** | 前置加工层已解锁 + 关键事件触发 | 完成遭遇战、特定任务或主动申请 | NPC在玩家触发事件后解锁供应 |

### 2.4 开发进度与解锁

开发进度采用**暗线指标**机制：

- **进度累积**：玩家向经济系统供需清单交付物资时，经济系统调用制造建造系统，自动累积对应开发节点的进度
- **进度显示**：玩家可通过专门的"开发进度面板"查看各节点进度与前置条件
- **解锁触发**：进度满或关键事件触发后，节点解锁，基地日志/新闻通知，同时通知经济系统更新相关状态
- **解锁效果**：解锁下游节点的前置条件、允许建造对应生产设施、通知经济系统开放对应物资交易与配额

### 2.5 开发树新闻通知

开发进度的关键节点通过**新闻通知**体现（瘟疫公司风格），玩家不需要主动查看面板就能感受到基地的发展：

| 通知类型 | 示例 |
|----------|------|
| 产地解锁 | 📢 勘探队发现新铁矿脉！铁矿区物流线准备贯通 |
| 物流事件 | ⚠️ 3号物流线遭叛军袭击，铁矿石供应暂时中断 |
| 加工线投产 | 🏭 钢铁加工线正式投产！炮弹产能提升 |
| 装备解锁 | 🚀 基地宣布：基础载具供应已就绪，可申请配额 |
| 阶段升级 | 🎉 先遣基地达成钢铁供应目标，启动二期扩建 |

### 2.6 进度推进规则

交付物资对开发进度的推进按以下规则：

| 规则 | 说明 |
|------|------|
| 单位推进值 | 每单位物资推进对应开发节点1点进度 |
| 节点总量 | 每个开发节点需要的进度总量在面板上显示（如铁矿脉群需1000点） |
| 批量推进 | 批量交付按数量线性推进 |
| 阶段加成 | 开发进度达50%后，NPC并行贡献开始加速进度（模拟其他先遣队员也在推进） |
| 玩家贡献占比 | 玩家交付贡献30%，NPC并行贡献70%（进度达50%后NPC贡献生效） |

## 3 生产设施

### 3.1 生产设施定位

生产设施是制造建造系统的核心产出单元，玩家通过建造生产设施，将原材料加工为工业品，产出存入基地仓库供经济系统调配。

**生产设施特点**：
- **自动化生产**：设施建成后持续自动产出，玩家无需反复操作
- **规模弹性**：玩家可根据需求选择小规模（自用）或大规模（补足供应链）
- **战略决策**：玩家精力放在"建什么、建在哪、多大"的决策上
- **与开发树联动**：生产设施的建造依赖开发树前置节点已解锁

### 3.2 生产设施类型

#### 3.2.1 冶炼炉（金属冶炼）

| 设施名称 | 产出物资 | 依赖原材料 | 前置开发节点 |
|----------|----------|------------|-------------|
| 小型铁矿炉 | 铁锭（REF001） | 铁矿石 | 铁矿脉群解锁 |
| 中型钢铁炉 | 钢锭（REF002）、高强钢锭（REF003） | 铁矿石、铁氧体 | 铁矿脉群解锁 |
| 大型铜铝炉 | 铜锭（REF004）、铝锭（REF006） | 铜矿石、铝土矿 | 铜矿脉群解锁 |
| 钛合金炉 | 钛锭（REF008）、钛合金锭（REF009） | 钛矿 | 钛矿脉群解锁 |
| 钨钢炉 | 钨钢（REF021） | 钨矿石、钢锭 | 钨矿石解锁 |

#### 3.2.2 化工厂（化工产品）

| 设施名称 | 产出物资 | 依赖原材料 | 前置开发节点 |
|----------|----------|------------|-------------|
| 基础化工厂 | 硫酸（REF016）、盐酸（REF024） | 硫磺、盐矿 | 硫磺矿解锁 |

| 制药厂 | 生物酶解修复剂（POT010）、抗生素 | 生物材料、农产品 | 生物材料供应解锁 |

#### 3.2.3 制造工厂（工业品）

| 设施名称 | 产出物资 | 依赖原材料 | 前置开发节点 |
|----------|----------|------------|-------------|
| 零件加工厂 | 螺栓、齿轮、轴承（IND001-004） | 钢锭、铝锭 | 钢铁加工线解锁 |
| 电子工厂 | 电路板、芯片（IND007-008） | 硅晶、铜锭、稀土 | 电子工业线解锁 |
| 弹药工厂 | 炮弹、导弹（AMM001-015） | 钢锭、铜锭、火药 | 钢铁加工线解锁 |
| 装甲工厂 | 装甲板毛坯（IND016） | 钢锭、钛锭 | 钢铁加工线解锁 |

### 3.3 建造与运行

#### 3.3.1 建造流程

```
1. 玩家选择建造地点（需在已解锁的据点/基地内）
   ↓
2. 选择建造的设施类型
   ↓
3. 系统检查前置条件
   ├── 开发树节点是否解锁
   ├── 建造所需物资是否充足（玩家通过经济系统获取）
   └── 建造地点是否有足够空间
   ↓
4. 消耗物资，触发建造
   ├── 小型设施：即时完成
   ├── 中型设施：1-2游戏小时
   └── 大型设施：4-8游戏小时
   ↓
5. 建造完成，设施开始运行
```

#### 3.3.2 建造所需物资

| 设施类型 | 建造物资 |
|----------|----------|
| 小型铁矿炉 | 钢锭×50、混凝土块×20 |
| 中型钢铁炉 | 钢锭×200、混凝土块×80、螺栓×100 |
| 大型铜铝炉 | 钢锭×300、铜锭×100、混凝土块×100 |
| 钛合金炉 | 钢锭×400、钛锭×50、混凝土块×150 |
| 弹药工厂 | 钢锭×500、铜锭×200、螺栓×200、混凝土块×200 |

> 建造物资通过经济系统的供需清单或交易终端获取。

#### 3.3.3 运行机制

**持续产出**：设施建成后自动持续产出，无需玩家操作。

**产出速率**：

| 设施规模 | 单小时产出 | 说明 |
|----------|-----------|------|
| 小型 | 1-5单位 | 仅供自用 |
| 中型 | 10-50单位 | 可供应基地 |
| 大型 | 50-200单位 | 补足供应链 |

**产出存储**：产出物资存入基地仓库，经济系统据此管理库存与价格。

**中断条件**：
- 原材料不足：设施暂停产出，待原材料补充后恢复
- 物流线中断：相关原材料供应受阻，设施产出下降50%
- 设施损坏：战斗中设施可能受损，需维修后恢复

### 3.4 规模弹性

玩家可根据需求调整生产规模：

| 需求场景 | 建造策略 | 投入产出比 |
|----------|----------|-----------|
| 自用需求 | 建造1-2座小型设施 | 低投入，自给自足 |
| 基地供销 | 建造3-5座中型设施 | 中投入，稳定收益 |
| 供应链补全 | 建造大型设施集群 | 高投入，解锁装备供应 |

**示例**：
- 玩家仅需75mm炮弹自用：建造1座小型弹药工厂，每小时产出5发
- 玩家想供应基地钢铁：建造3座中型钢铁炉，每小时产出30钢锭
- 玩家想解锁高级载具：建造大型钛合金炉+电子工厂集群，补足供应链缺口

## 4 物流系统

### 4.1 物流系统定位

物流系统连接原材料产地与加工设施，是开发树第一层（原材料供应）与第二层（工业品加工）之间的纽带。

**物流系统特点**：
- **半显性**：物流线需要解锁，解锁后自动连接，但容量有限
- **风险存在**：物流线运行中可能触发减益事件，需玩家维护
- **可扩展性**：当前为被动减益模式，未来可扩展为任务响应模式
- **与经济系统联动**：物流线状态直接影响经济系统的物资价格波动

### 4.2 物流线解锁

#### 4.2.1 解锁条件

物流线的解锁需要同时满足：

1. 原材料产地已解锁（通过探索/占领，归属开发树第一层）
2. 完成物流清障任务（首次解锁）

#### 4.2.2 物流清障任务

物流清障任务是一次性任务，解锁物流线后不再需要重复完成。

**任务示例**：

| 任务名称 | 任务目标 | 任务奖励 |
|----------|----------|----------|
| 1号物流线清障 | 前往铁矿脉群附近的物流节点，清除残留叛军 | 解锁铁矿→基地的物流线①，信用点×500（通过经济系统发放） |
| 2号物流线清障 | 前往铜矿脉群附近的物流节点，击退小规模虫群 | 解锁铜矿→基地的物流线②，信用点×800（通过经济系统发放） |

**任务流程**：
```
1. 基地发布清障任务
   ↓
2. 玩家接取任务
   ↓
3. 玩家前往任务地点（已解锁的地图位置）
   ↓
4. 触发战斗/事件
   ├── 清除叛军/虫群 → 任务完成 → 物流线解锁
   └── 战斗失败 → 任务失败，可重试
```

### 4.3 物流线运行

#### 4.3.1 运行状态

物流线解锁后自动运行，将原材料从产地运输至基地仓库。

**运行参数**：

| 参数 | 说明 |
|------|------|
| 运输速率 | 每小时运输100-500单位原材料 |
| 运输容量 | 单条物流线最大同时运输1000单位 |
| 连接范围 | 物流线仅连接对应产地与基地 |

#### 4.3.2 物流线管理

**物流线升级**：玩家可投入物资升级物流线，提升运输速率与容量。

| 升级等级 | 运输速率 | 运输容量 | 升级费用 |
|----------|----------|----------|----------|
| Lv1（初始） | 100单位/小时 | 1000单位 | 解锁时免费 |
| Lv2 | 200单位/小时 | 2000单位 | 钢锭×100、螺栓×200 |
| Lv3 | 300单位/小时 | 3000单位 | 钢锭×200、铜线×100、螺栓×400 |

**物流线面板**：

```
┌─────────────────────────────────────────────────┐
│              物流线管理                           │
├─────────────────────────────────────────────────┤
│                                                 │
│  ① 铁矿→基地                                    │
│  状态：✅ 运行中                                  │
│  运输速率：200单位/小时                           │
│  当前容量：1500/2000单位                          │
│  物流线等级：Lv2                                 │
│  [升级至Lv3]                                    │
│                                                 │

│  状态：⚠️ 运输受阻（铁矿石供应-50%）              │

│  当前容量：500/1000单位                           │

│                                                 │

```

### 4.4 物流线风险事件

#### 4.4.1 事件类型

物流线运行中可能触发以下减益事件：

| 事件类型 | 触发概率 | 减益效果 | 处理方式 |
|----------|----------|----------|----------|
| 数字叛军袭击 | 低 | 对应原材料供应-50%，持续3游戏天 | 被动减益，可前往触发点处理 |
| 虫群阻断 | 中 | 对应原材料供应-30%，持续2游戏天 | 被动减益，可前往触发点处理 |
| 设备故障 | 低 | 运输速率-30%，持续1游戏天 | 被动减益，自动恢复 |
| 气候异常 | 极低 | 物流线暂停，持续半天 | 被动减益，自动恢复 |

#### 4.4.2 事件处理

**被动减益模式**（当前实现）：
- 事件触发后，物流线自动施加减益
- 减益信息显示在物流线面板与基地日志
- 减益会在一段时间后自动恢复
- 玩家可选择前往事件地点处理，到达后自动触发清障任务，解决后立即取消减益
- **同时通知经济系统**：物流线状态变化时，经济系统据此调整对应物资价格

**未来扩展（任务响应模式）**：
- 事件触发后，生成可接取的清障任务
- 玩家必须完成任务才能取消减益
- 减益期间物资供应暂停，迫使玩家响应

#### 4.4.3 事件通知

事件触发时通过以下方式通知玩家：

1. **基地日志**：⚠️ "2号物流线遭虫群阻断，铜矿石供应下降30%"
2. **物流线面板**：显示减益状态与"前往处理"按钮
3. **地图标记**：触发事件的物流节点显示红色标记
4. **经济系统通知**：同步通知经济系统调整相关物资价格

## 5 与经济系统的接口

### 5.1 接口概述

制造建造系统作为"生产能力的控制者"，向经济系统暴露以下状态查询接口。经济系统通过这些接口决定物资是否可交易、配额是否可领取、价格如何波动。

### 5.2 状态查询接口

| 查询内容 | 查询方 | 返回内容 | 用途 |
|----------|--------|----------|------|
| 某开发节点是否已解锁 | 经济系统 | 是/否 | 决定对应物资是否在交易终端上架、配额是否开放 |
| 某开发节点当前进度 | 经济系统 | 百分比 | 用于交易终端价格波动（开发进度修正） |
| 某物流线当前状态 | 经济系统 | 运行中/受阻/中断 | 用于交易终端价格波动（物流状态修正） |
| 某物流线供应减益系数 | 经济系统 | 0~1 | 用于计算原材料供应下降比例 |
| 基地某物资库存 | 经济系统 | 数量 | 用于交易终端价格波动（库存修正） |
| 某设施是否已建造 | 经济系统 | 是/否 | 用于判断玩家是否拥有某条生产线 |

### 5.3 事件通知接口

| 通知事件 | 通知方 | 接收方 | 处理 |
|----------|--------|--------|------|
| 开发节点解锁 | 制造建造系统 | 经济系统 | 更新供需清单、解锁配额、上架交易终端物资 |
| 物流线中断 | 制造建造系统 | 经济系统 | 上调对应物资价格 |
| 物流线恢复 | 制造建造系统 | 经济系统 | 下调对应物资价格 |
| 设施产出入库 | 制造建造系统 | 经济系统 | 更新基地仓库库存 |
| 物资交付请求 | 经济系统 | 制造建造系统 | 计算并推进对应开发节点进度 |

## 6 技术实现要点

### 6.1 核心数据属性

#### 6.1.1 开发树节点

开发树节点是开发树的基本单元，需记录以下属性：

| 属性 | 用途 |
|------|------|
| 节点ID | 唯一标识，用于前置依赖的引用 |
| 节点名称 | 面板与通知中显示的名称 |
| 层级 | 标记节点所属的层级（第一层原材料/第二层工业品/第三层装备），用于控制解锁逻辑分支 |
| 类型 | 区分原材料产地、加工生产线、装备供应，决定解锁条件与奖励类型的分支 |
| 前置依赖列表 | 记录所有前置节点的ID，用于判断该节点是否可以开始推进进度 |
| 当前进度 | 记录已累积的交付量，与解锁所需总量比较 |
| 解锁所需进度 | 该节点的进度阈值，达到即触发解锁 |
| 是否已解锁 | 标记节点状态，解锁后不再接受进度推进，同时开放下游节点的依赖 |
| 解锁奖励 | 记录解锁后触发的效果类型与目标ID（如允许建造某设施、通知经济系统开放某项配额） |
| 新闻文本 | 节点解锁时在日志/通知中显示的消息内容 |

#### 6.1.2 生产设施

生产设施是制造系统的运行单元，需记录以下属性：

| 属性 | 用途 |
|------|------|
| 设施ID | 唯一标识 |
| 设施名称 | 建造面板与设施列表中显示的名称 |
| 设施类型 | 区分冶炼炉/化工厂/制造工厂等，决定可建造的设施种类与外观 |
| 规模等级 | 标记设施的小/中/大规模，决定产出速率与建造消耗 |
| 所在位置 | 设施建造的据点或基地区域，用于空间管理 |
| 产出物资ID | 设施产出的物品ID，关联物品设计书 |
| 产出速率 | 每小时自动产出的数量，由规模等级决定 |
| 存储上限 | 设施内置仓库的容量，满后暂停产出直至玩家领取 |
| 消耗物资ID | 设施运行所需的原材料ID |
| 消耗速率 | 每小时消耗的原材料数量，通常略高于产出速率 |
| 是否已建造 | 标记设施是否完成建造，未完成时不产出 |
| 建造时间 | 从开始建造到完成所需的时间，由规模决定 |
| 当前库存 | 设施当前已产出但未领取的物资数量 |
| 是否运行中 | 标记设施是否在产出，原材料不足或损坏时为否 |
| 是否损坏 | 标记设施是否因战斗受损，损坏后需维修才能恢复 |

#### 6.1.3 物流线

物流线连接原材料产地与基地仓库，需记录以下属性：

| 属性 | 用途 |
|------|------|
| 物流线ID | 唯一标识 |
| 物流线名称 | 面板中显示的名称（如"铁矿→基地"） |
| 起点位置 | 原材料产地的地图位置标识 |
| 终点位置 | 基地仓库的位置标识 |
| 等级 | 物流线的升级等级，决定运输速率与容量 |
| 运输速率 | 每小时从产地运输至基地的原材料数量 |
| 运输容量 | 物流线同时可承载的最大运输量 |
| 当前运输量 | 当前正在运输中的物资数量 |
| 运行状态 | 区分运行中/运输受阻/未解锁三种状态，控制物流线行为 |
| 供应减益系数 | 当发生风险事件时，记录原材料供应的下降比例（0为正常，0.5为下降50%） |
| 当前事件列表 | 记录物流线上正在生效的风险事件，用于面板展示与事件处理 |

### 6.2 核心计算逻辑

#### 6.2.1 开发进度计算

当经济系统收到玩家交付物资的请求时，调用制造建造系统计算开发进度：

1. **物资关联检查**：根据交付的物资ID查找供需清单（经济系统提供），确认该物资是否关联了某个开发树节点。若未关联则仅计算信用点，不推进进度。
2. **节点状态检查**：查找关联的开发节点，确认该节点尚未解锁（已解锁的节点不再接受进度推进）。
3. **进度累积**：将本次交付的物资数量作为进度增量，累加至节点当前进度上，但不超过解锁所需总量。
4. **NPC并行贡献**：当节点进度达到50%后，NPC并行贡献开始生效，自动加速剩余进度，模拟"其他先遣队员也在推进"的效果。
5. **解锁判定**：若累加后的进度达到或超过解锁所需总量，触发节点解锁——标记为已解锁、执行解锁奖励、发送新闻通知、开放下游节点依赖、通知经济系统更新相关状态。

#### 6.2.2 设施产出计算

设施每小时自动产出时：

1. **原材料检查**：检查设施所需原材料在基地仓库中是否充足。
   - 充足：按产出速率生产，从仓库扣除对应数量的原材料。
   - 不足：设施标记为暂停，等待原材料补充。
2. **物流线检查**：检查关联的物流线是否正常运行。
   - 正常：按标准产出速率生产。
   - 受阻：产出速率乘以（1 - 减益系数）。
3. **库存检查**：检查设施当前库存是否已达存储上限。
   - 未满：产出物资累加至设施库存。
   - 已满：设施暂停产出，等待玩家领取。
4. **入库通知**：产出物资从设施库存转移至基地仓库时，通知经济系统更新库存数据。

#### 6.2.3 物流线事件触发

物流线运行中随机触发风险事件：

1. **概率判定**：根据各事件类型的触发概率，进行随机判定。
2. **事件生效**：判定成功后，在物流线上添加对应事件，设置持续时间和减益效果。
3. **状态更新**：更新物流线的运行状态和供应减益系数。
4. **通知经济系统**：将物流线状态变化通知经济系统，触发价格波动。
5. **事件结束**：持续时间结束后，自动移除事件，恢复物流线状态，再次通知经济系统。

## 8 小结

本设计书定义了织女-7先遣星球的制造建造系统，核心框架包括：

1. **开发树**：三层树状结构（原材料→工业品→装备成品），控制生产能力的解锁顺序，是制造建造系统的核心进度机制。
2. **生产设施**：冶炼炉、化工厂、制造工厂三大类，建成后持续自动产出，规模弹性可调。
3. **物流系统**：半显性、有风险的连接系统，连接原材料产地与基地仓库，影响生产设施的原材料供应。
4. **与经济系统的接口**：制造建造系统向经济系统暴露状态查询接口，经济系统消费开发树状态决定物资交易与配额开放。

制造建造系统与 [经济系统设计书](file:///workspace/设计文档/经济系统设计书.md) 紧密耦合但职责分明：制造建造系统管"能不能生产"，经济系统管"怎么交易"。两者通过清晰的接口对接，共同构成完整的星球资源开发与流通体系。
