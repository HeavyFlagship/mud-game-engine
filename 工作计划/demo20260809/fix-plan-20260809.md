## 二、修改方案

### 任务 A：雷达 Canvas 绘制危害区 + 状态提示

**涉及文件**：
- `assets/js/systems/battle-ui.js` —— `updateRadar()` 方法
- `assets/js/systems/battle.js` —— `updateHazards()` 方法（添加状态提示）

**具体改动**：

#### A1：Radar 绘制危害区（battle-ui.js `updateRadar()`）

在绘制完网格背景后、绘制 NPC/敌人之前，遍历 `Battle.battlefield.hazards` 绘制危害圈：

- 酸液池（`acid_pool`）：半透明红色填充圆 + 红色虚线边框
- 电磁干扰区（`emi` / `em_interference`）：半透明蓝色填充圆 + 蓝色虚线边框
- 毒雾区（`toxic_fog`）：半透明绿色填充圆 + 绿色虚线边框
- 使用 `ctx.arc()` 按危害位置和半径绘制，位置根据玩家坐标换算到画布坐标（与玩家/敌人位置换算逻辑一致）

#### A2：状态提示（battle.js `updateHazards()`）

在危害生效时通过 `Msg` 输出提示或在玩家状态面板显示当前危害状态。最简单的方式：
- 进入危害区时，一次性输出 `Msg.warn('⚠ 进入<危害名>——<效果描述>')`
- 离开危害区时，输出 `Msg.info('已离开<危害名>')`
- 使用 `Player._hazardStatus` 记录当前所在危害类型，避免重复提示

### 任务 B：地图 UI 调整为二级层次

**涉及文件**：
- `assets/js/systems/game.js` —— 新增 `updateRegionMap()` 替换当前 `updateMinimap()`
- `assets/styles.css` —— 新增区域地图样式
- `mud-game-engine.html` —— 可能调整地图容器尺寸 / 标题

**设计原则**：
- 第二级（区域地图）替换当前"世界地图"面板，使用 Canvas 渲染。
- 第三级（场景战场）保持现有雷达 Canvas，叠加危害绘制（任务 A）。
- 一级暂不实现。

**具体改动**：

#### B1：区域地图 Canvas（game.js）

新增 `updateRegionMap()` 方法，替换 `updateMinimap()`：

- 使用 Canvas 替代 HTML div 网格（新建 `<canvas id="region-map-canvas">` 替换旧 `#minimap` div）
- 画布大小：440×440px（11×11 格，每格 40px）
- 以玩家当前房间 `(x, y)` 为中心，显示 11×11 范围
- 每格绘制：
  - **底色**：按地貌类型（terrain）着色，对应色表：
    - `cave` → 深灰 `#2a2a2a`
    - `crystal` → 幽蓝 `#1a3a5a`
    - `sandy` → 土黄 `#4a3a2a`
    - `rocky` → 灰棕 `#3a3a3a`
    - `metal_floor` → 青灰 `#2a3a4a`（安全区）
    - 默认 → `#1a2a1a`
  - **边框**：当前房间高亮（青色边框 2px），已探索/未探索区分
  - **特征图标**（小字或色点）：
    - Boss 房间 → 💀
    - 安全区 → 🏠
    - 有危害区 → ⚠（红色小三角）
    - 有资源点 → ⛏（黄色小点）
    - 有 NPC → 👤
  - **玩家位置**：青色闪烁光点
- 保留图例（Canvas 底部文字）
- 移除旧 `#minimap` div 相关 CSS

#### B2：HTML 结构调整（mud-game-engine.html）

- 将 `<div id="minimap">` 替换为 `<canvas id="region-map-canvas" width="440" height="440">`
- 更新标题从"世界地图"为"区域地图"
- 保留 `#map-level-info` 和 `#minimap-legend`（改为 Canvas 内绘制）

#### B3：CSS 样式调整（styles.css）

- 移除旧 `.minimap` / `.map-cell` 相关样式
- 新增 Canvas 容器样式（如需要）
