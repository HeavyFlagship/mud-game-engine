## 1. 概述

### 1.1 Demo目标
制作一个**核心循环完整可玩**的Demo版本，玩家可以：
1. 从基地出发，探索10x10的网格地图
2. 遭遇虫族和机械敌人，进入时间轴回合制战斗
3. 击败敌人获得战利品和信用点
4. 返回基地购买装备/载具、补充弹药
5. 挑战Boss房间，完成探索目标

### 1.2 Demo范围（已确认）
| 维度 | 范围 |
|------|------|
| 地图 | 10x10网格（100个房间），包含基地、荒原、矿洞、机械遗迹等区域 |
| 敌人 | 约15种（虫族8-10种 + 机械5-6种），含Boss |
| 制造 | 基础弹药制造（在基地内通过战利品兑换/制造弹药） |
| 经济 | 维持现有金币商店，扩展商品种类 |

### 1.3 不实现的功能
以下功能明确**不在本次Demo范围内**：
- 完整制造链（开发树、冶炼炉、化工厂等）
- 完整经济系统（供需子系统、配额制、价格波动、跨基地交易）
- 叛变数字生命阵营敌人
- 人物技能等级系统（五维技能树）
- 装备品质与词缀系统
- 护盾系统
- 小队/队友系统
- 电子战指令（EW Commands）
- 防御指令
- 100x100完整地图
- 物流系统

## 7. 假设与决策

| 决策 | 理由 |
|------|------|
| 10x10地图使用程序化生成而非手工设计 | 100个房间手工设计工作量过大，且Demo重点是验证场景系统 |
| 制造系统仅做弹药制造 | 弹药是战斗核心消耗品，制造弹药让战利品收集有意义 |
| 任务系统仅做简单的击杀/收集任务 | 验证任务框架，未来可扩展复杂任务链 |
| 技能系统暂不接入 | 技能系统需要与五维技能树联动，Demo阶段复杂度过高 |
| 电子战设备可购买但暂不实现EW指令 | 装备数据已就绪，但交互指令较复杂 |
| 保持现有金币经济 | 完整经济系统（供需/配额/价格波动）需要大量后端逻辑 |
