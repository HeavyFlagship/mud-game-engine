# 采矿作业设计书 · 大纲（待细化）

> **状态**：大纲定稿（2026-08-31），正文细化待用户确认
> **原则**：采矿工作**主要依靠人工操作机械完成，而非自动开采**；可采矿场景存在**矿区**；矿区采矿需**携带（载具装载）采矿设备**；与建造联动但**以辅助设施为主，无直接采矿设施**
> **参考**：[世界场景设计书 §4.4.5 矿脉表](../设计文档/世界场景设计书.md#L443-L452)、[物品设计书 §3 矿产](../设计文档/物品设计书.md#L81-L106)、[玩家成长设计书 §4 机制配套](../设计文档/玩家成长设计书.md#L259-L277)、[战斗系统设计书 §3.4 时间消耗](../设计文档/战斗系统设计书.md#L473-L474)

## §1 概述

- 补齐"采矿精通"技能索取的**矿脉资源丰度/耗尽机制**（[玩家成长 §4](../设计文档/玩家成长设计书.md#L265)）。
- 明确"采矿 = 人工操作机械"的作业定位，与基地自动产线（H5 深层采矿站）并存不冲突（决策 D3）。

## §2 矿区概念

- 2.1 **矿区实体**：场景内一个矿区 = 一个"矿区实体"，内含 1~N 个**矿点**；对应 [世界场景矿脉表](../设计文档/世界场景设计书.md#L443-L452) 的 6 类矿脉。
- 2.2 **矿点数据结构**：`矿脉类型 / 总储量 / 当前储量 / 富集系数 / 状态（富矿/贫矿/枯竭）`。
- 2.3 **矿区规模分级**：小型 / 中型 / 大型 / 富集，用于决定矿点数、储量上限与威胁等级。
- 2.4 **矿区与场景关系**：矿脉 `lootPoints` 升级为矿区实体；矿区含威胁刷新点与辅助设施位（§7）。

## §3 采矿设备（载具装备）

- 3.1 **设备属性**：采矿设备 = **载具装备**，占用载具接口/货舱/资源（能耗、功率）；不分手持/背包；**机体（人形载具）同样装载此类装备**（决策 D4）。
- 3.2 **设备分级**（按效率与能耗分档）：
  - 轻型采矿模块：低效率 / 低能耗 / 小占位
  - 中型采矿模块：中等效率 / 中能耗 / 中占位
  - 重型采矿模块：高效率 / 高能耗 / 大占位
- 3.3 **安装与装卸**：按载具装备管理（安装/拆卸、接口匹配校验）；"采矿精通"优化位：效率提升、解锁贫矿开采。
- 3.4 **设备状态**：耐久、能耗、损坏与维修（辅助设施维修/充能，§7）。

## §4 采矿作业流程

- 4.1 **前置检查**：到达矿区 + 载具已安装采矿设备 + 安全确认（威胁等级判定）。
- 4.2 **作业单元**：单次作业 = 1 个作业单元（约 X 分钟游戏时间，计入时间轴，对齐 [战斗 §3.4](../设计文档/战斗系统设计书.md#L473-L474)）。
- 4.3 **产出结算**：`产出量 = 设备效率 × 矿点富集系数 × 单次基础产量 × 状态修正`；作业结束即时入货舱/仓库。
- 4.4 **中断与撤离**：遇敌 / 环境危害 / 设备损坏时中断，已采部分即时结算，可随时撤离。

## §5 矿脉资源丰度与耗尽（核心）

- 5.1 **储量消耗规则**：每作业单元消耗矿点储量，储量 → 0 前矿点由"富矿"逐步降为"贫矿"。
- 5.2 **枯竭判定与惩罚**：储量归零 → 矿点枯竭；惩罚包括产出骤降、触发虫群滋生事件、该矿点不可再采——对应"采矿达成耗尽条件时承受惩罚"（[玩家成长 §4](../设计文档/玩家成长设计书.md#L265)）。
- 5.3 **恢复规则**：枯竭矿点低速自然恢复或事件补充（地质活动），避免全图永久枯竭。

## §6 采矿产出

- 6.1 **产出映射**：矿石种类/数量/稀有度 → [物品 MIN 表](../设计文档/物品设计书.md#L85-L106)（铁/铜/钛/辉锗/稀土/烃/硫磺/冰/石矿等）。
- 6.2 **特殊产出**：辉锗富集（富集系数）、稀有伴生矿物、与虫群相关的矿石类战利品来源。

## §7 采矿与建造联动（辅助设施为主）

- 7.1 **辅助设施清单**（处理/支持型，**无直接采矿设施**）：
  - 矿石临时仓储站：自动收纳矿产物，防货舱满载中断作业。
  - 设备维修/充能站：恢复采矿模块耐久与能耗。
- 7.2 **与建筑系统的关系**：设施安装/所有权走建筑系统接口；本轮仅定义联动点，建造细节待建筑系统（决策 D5）。

## §8 矿区威胁与环境

- 矿区敌人刷新规则（虫群偏好矿脉，B6 辉锗矿脉虫窟等）；环境危害（电磁干扰、低温、塌方）；威胁等级影响作业安全（§4.1）。

## §9 指令设计

对齐 [世界场景 §4.7 探索层](../设计文档/世界场景设计书.md#L556-L566) 建议指令：

| 指令 | 功能 |
|------|------|
| `采矿` / `mine` | 在矿区开始一次采矿作业（需设备） |
| `查看矿脉` / `prospect` | 查看当前矿区矿点储量/富集度/状态 |
| `安置` / `deploy` | 安装/拆卸采矿模块（或并入装备管理指令） |
