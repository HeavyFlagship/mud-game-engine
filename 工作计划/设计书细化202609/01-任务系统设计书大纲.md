## §1 概述

- **设计目标**：以任务为探索/战斗/经济/成长的**组织框架**，消除文档中所有"任务接取/交付（待定）"占位，让任务成为地块目标、事件触发与奖励结算的统一入口。
- **与现行代码的关系**（本设计书允许参考代码实现）：
  - `NPCDB[dialog].quest` 目前是**纯文本任务简报**（[npcs.js](../mud-game-engine/assets/js/data/npcs.js#L8-L18)），无结构化状态。
  - `talk <npc> 任务` 仅把简报逐行输出（[game.js](../mud-game-engine/assets/js/systems/game.js#L575-L603)）。
  - `Battle.setPlayerTask()` 的 `playerTask` 实为**战斗行动序列**（move/call/wait，[battle.js](../mud-game-engine/assets/js/systems/battle.js#L314-L329)），与"任务系统"命名相近但语义不同——大纲阶段即澄清，避免后续混淆。
  - **改造路径**：文本简报 → 结构化任务定义（接取/进行/交付状态机），文字保留作为"简报展示文本"字段。

## §2 任务类型与结构

- **2.1 主线任务**：章节推进，承接 32 处特殊地点的核心剧情线（H2 主线第1章 → B1 清剿 → B6 夺回矿脉 → A8 解谜主线 → B11 终章等）。
- **2.2 支线任务**：由地点/事件触发（见 §5.2 地点任务关联表）。
- **2.3 组织任务**：由玩家成长"组织信任"技能解锁的类目（[玩家成长 §2.6](../设计文档/玩家成长设计书.md#L164-L177)），内容待组织系统概念落地。
- **2.4 循环任务**：可重复类（矿脉护航、虫群压制、哨所坚守、断虫道等），用于长期材料/配额供给。

## §3 任务生命周期

- **3.1 状态机**：`可接取 → 进行中 → 完成（待交付）→ 已交付`；含 `失败`/`放弃` 分支（进入冷却或需重接）。
- **3.2 接取条件**：前置任务 / 组织信任等级 / 地点发布（NPC 对话或地点事件）。
- **3.3 交付方式**：NPC 对话交付 / 指定地点交付 / 系统自动交付（声望类目标）。
- **3.4 并行与冲突**：主线+支线+循环可并行数量上限、同类循环任务互斥规则。

## §6 任务奖励

- **6.1 信用点 / 物品 / 装备蓝图**：承接 [装备系统设计书 §1.3.2 任务奖励](../设计文档/装备系统设计书.md#L86-L94)。
- **6.2 经验**：任务结算奖励**引导指定维度**经验（社会/知识等，见[玩家成长 §3.3](../设计文档/玩家成长设计书.md#L210-L220)），并计入"完成任务"的社会经验来源。
- **6.3 配额与经济开放**：任务完成后开放物资配额/供需条目（示例：辉锗矿脉清剿任务 → 开放辉锗晶体配额，[经济设计书](../设计文档/经济系统设计书.md#L853)）。
- **6.4 开发树解锁**：任务完成可直接解锁/加速开发树节点（如"玩家直接生产路径"外的第三条路径：任务交付即解锁；或缩短 NPC 解锁窗口），承接 [制造生产系统设计书 §2 开发树](../设计文档/制造生产系统设计书.md)。

## §7 指令设计

对齐 [世界场景 §4.7.1](../设计文档/世界场景设计书.md#L568-L582) 基地服务层"任务（待定）"占位，建议指令：

| 指令 | 功能 |
|------|------|
| `任务` / `quest` | 查看当前任务列表与进度（追踪） |
| `任务 接取 <名称>` | 向当前 NPC 接取任务 |
| `任务 交付 <名称>` | 向当前 NPC 交付任务 |
| `任务 放弃 <名称>` | 放弃任务 |
