# 幻境传说 / MUD 文字冒险引擎

一个基于 HTML/CSS/JavaScript 的纯前端 MUD 文字游戏引擎，附带科幻主题的完整游戏内容。玩家扮演意识上传到电子脑的先遣队员，在外星球上探索、战斗、收集资源。

## 项目简介

未来人类掌握了受限虫洞跳跃技术，传送质量上限约为 2 千克。恰好，一个成年人类大脑约 1.4 千克——"只送大脑"从科幻寓言变成了工程现实。人类将意识上传到电子脑，派遣先遣队员前往外星球建立工业体系。游戏故事发生在一颗代号"织女-7"的先遣星球上。

## 当前功能

- **指令系统**：自然语言解析，支持别名和模糊匹配
- **战斗系统**：回合制战斗，技能/药水/逃跑，暴击、部位破坏、状态效果
- **地图系统**：3D 坐标网格（x/y/z），矿洞地下层，小地图显示
- **装备系统**：武器、防具、饰品、药水，装备槽位和属性加成
- **存档系统**：LocalStorage 本地存档，支持增量地图变更记录
- **查询窗口**：右侧独立查询面板，分流状态/背包/技能/地图等查询输出

## 快速开始

直接在浏览器中打开 `mud-game-engine/mud-game-engine.html` 即可运行，无需服务器或构建步骤。

```bash
cd mud-game-engine
# 用浏览器打开 mud-game-engine.html
```

支持 Chrome、Firefox、Edge 等现代浏览器。

## 游戏指令

| 指令 | 说明 |
|------|------|
| `look` / `l` | 查看当前房间 |
| `north` / `n` | 向北移动 |
| `south` / `s` | 向南移动 |
| `east` / `e` | 向东移动 |
| `west` / `w` | 向西移动 |
| `up` / `u` | 向上移动 |
| `down` / `d` | 向下移动 |
| `pick [物品名/编号]` | 拾取物品 |
| `drop [物品名]` | 丢弃物品 |
| `equip [装备名]` | 穿戴装备 |
| `unequip [槽位]` | 卸下装备 |
| `attack` / `a` | 攻击 |
| `skill [技能名]` | 使用技能 |
| `potion` | 使用药水 |
| `flee` | 逃跑 |
| `status` / `sta` | 查看角色状态 |
| `bag [-d]` | 查看背包（-d 显示详情） |
| `skills` | 查看技能 |
| `map` | 查看地图 |
| `save` | 存档 |
| `load` | 读档 |
| `help` | 查看帮助 |

## 技术特点

- **纯前端**：无后端依赖，单 HTML 入口，模块化 JS 文件
- **响应式 UI**：侧边栏状态面板 + 主命令行窗口 + 右侧查询窗口
- **增量存档**：只记录地图变更而非完整地图状态，减少存档体积
- **3D 地图**：支持 z 轴坐标，矿洞等地下场景
- **模块化设计**：数据层、系统层、表现层分离，便于扩展
